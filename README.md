# 伺かの教科書

デスクトップに住むキャラクター「ゴースト」で遊ぶところから、自分のゴーストを作って配布するところまでを、順番に学べる教科書です。会話を書く言語（SHIORI）は **里々** と **YAYA** の両方を扱います。

## この本の読み方

- **遊んでみたい人** … 第1部（第1〜3章）だけ読めば十分です。
- **ゴーストを作りたい人** … 第1部から第2部へ進み、第3部（里々）か第4部（YAYA）の**どちらか一方**を選んでください。迷ったら里々がおすすめです。台本を書く感覚で始められます。プログラミングの経験がある人は YAYA も向いています。
- 第5部・第6部は、どちらの SHIORI を選んだ人にも共通です。

本全体で、同じサンプルゴースト「はじめてのゴースト」（\0 側：**ことね**、\1 側：小鳥の **ぴーすけ**）を育てていきます。完成形の辞書は [`samples/`](samples/) にあります。
