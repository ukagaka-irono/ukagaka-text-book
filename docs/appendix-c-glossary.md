# 付録C 用語集

## この付録の使い方

- この本に出てくる伺か・SSP の用語の意味
- 同じものを指す別の呼び方（さくら側／\0 側 など）
- それぞれの用語を詳しく扱っている章

用語は「記号・アルファベット」と「五十音」に分けて並べています。説明の最後の「→」は、その用語を詳しく扱う章です。

## 記号・アルファベット

### \0 側／\1 側

ゴーストのキャラクターの呼び分け。**\0 側** はメインキャラクター（本体）、**\1 側** はサブキャラクター（相方）です。さくらスクリプトの `\0`（`\h` とも書く）と `\1`（`\u` とも書く）で話し手を切り替えることから、こう呼ばれます。「さくら側／うにゅう側」「本体側／相方側」も同じ意味です。→ [第1章](01-what-is-ukagaka.md)、[第6章](06-sakura-script.md)

### collision（コリジョン）

シェルの画像の上に設定する **当たり判定**（触れる場所）のこと。`surfaces.txt` に、範囲と名前（例：`Head`）を書いて定義します。ユーザーがその範囲をなでたりダブルクリックしたりすると、範囲の名前がマウスイベントの Reference としてゴーストへ伝わります。→ [第12章](12-shell.md)

### CROW（クロウ）

ベースウェアの一つ。SSP と同じく、伺かのゴーストを動かすことができます。→ [第1章](01-what-is-ukagaka.md)

### descript.txt

ゴースト・シェル・バルーンなどの基本情報を書く設定ファイル。名前、作者、使う SHIORI などを `項目名,値` の形で書きます。ゴーストの場合、`ghost/master/descript.txt` がないとベースウェアに認識されません。→ [第5章](05-descript.md)

### developer_options.txt

SSP 専用の設定ファイル。SSP で nar や `updates2.dau` を作るときに、含めないファイル（セーブデータなど）を指定します。→ [第15章](15-distribute.md)

### install.txt

nar ファイルの一番上のフォルダに置く、インストール設定ファイル。中身の種類（`type,ghost` など）やインストール先のフォルダ名を書きます。これがないと、ドラッグ＆ドロップによる自動インストールが働きません。→ [第5章](05-descript.md)、[第15章](15-distribute.md)

### MAKOTO（マコト）

ゴーストが話す文章の中の言葉を置き換える仕組み。語尾を変えて口調を変えるといった演出に使われます。通常は `makoto.dll` という DLL で提供されます。→ [第1章](01-what-is-ukagaka.md)

### MATERIA（マテリア）

本家の伺か（ベースウェアとしての伺か）の呼び名。「伺か」という言葉がジャンル全体を指すようになったため、ソフトウェアとしての伺かを区別してこう呼びます。→ [第1章](01-what-is-ukagaka.md)

### MAYUNA（マユナ）

シェルの **着せ替え** の仕組み。SERIKO の一種として実装されています。→ [第12章](12-shell.md)

### nar（ナー）

ゴースト・シェル・バルーン・プラグインなどを配布するためのファイル形式。「Nanika ARchive」の略で、中身は zip 形式の圧縮ファイルの拡張子を `.nar` に変えたものです。ベースウェアにドラッグ＆ドロップするとインストールできます。→ [第2章](02-install-ssp.md)、[第15章](15-distribute.md)

### OnBoot

ゴーストが起動したときに発生するイベント。最初のあいさつを返すのに使います。→ [第7章](07-shiori-events.md)、[付録B](appendix-b-events.md)

### Reference（リファレンス）

イベントに添えて SHIORI に渡される付加情報。`Reference0`、`Reference1`…と番号がつき、イベントごとに中身が決まっています。たとえば `OnBoot` の `Reference0` は起動時のシェル名です。→ [第7章](07-shiori-events.md)

### SAORI（サオリ）

SHIORI の機能を拡張するモジュール。SHIORI だけではできない処理（特別な計算やファイル操作など）を補います。多くは DLL として配布され、ゴーストの中に入れて使います。→ [第1章](01-what-is-ukagaka.md)

### SERIKO（セリコ）

シェルのアニメーションの仕組み。まばたきなどの動きを、サーフェスを切り替えたり重ねたりして表現します。`surfaces.txt` に設定を書きます。→ [第12章](12-shell.md)

### SHIORI（シオリ）

ゴーストの「頭脳」にあたるプログラム。ベースウェアからイベントを受け取り、辞書をもとにさくらスクリプトのセリフを組み立てて返します。里々や YAYA などの種類があり、通常は DLL として提供されます。→ [第7章](07-shiori-events.md)

### SSP

現在もっとも広く使われているベースウェア。多くのゴーストと互換性があり、複数ゴーストの同時起動、ネットワーク更新、プラグイン、開発者用機能などを備えています。名前はもともと「Sakura Script Player」の略でしたが、現在は特に何の略でもないとされています。→ [第2章](02-install-ssp.md)、[第3章](03-ssp-features.md)

### SSTP

「Sakura Script Transfer Protocol」の略。外部のソフトからゴーストにさくらスクリプトを送って話させるための仕組みです。

### surface（サーフェス）

シェルの画像の一コマ。キャラクターの表情一つ一つが一つのサーフェスで、番号（ID）で区別します。さくらスクリプトの `\s[番号]` で切り替えます。資料によって「サーフィス」「サーフェイス」とも書かれます。→ [第12章](12-shell.md)

### surfaces.txt

シェルの設定ファイル。当たり判定（collision）、アニメーション（SERIKO）、着せ替え（MAYUNA）などを、サーフェスごとに定義します。→ [第12章](12-shell.md)

### updates2.dau

ネットワーク更新のためのファイル。更新の対象となるファイルの一覧と、その MD5 ハッシュ値（壊れていないかを確かめるための値）が書かれています。人が手で書くものではなく、SSP の機能などで作ります。同じ役割の `updates.txt` もあります。→ [第15章](15-distribute.md)

### YAYA（ヤヤ）

SHIORI の一つ。C 言語に似た書き方で、条件分岐やくり返し、たくさんの組み込み関数が使えます。プログラミング経験のある人に向いています。「文（あや）」という SHIORI の後継として開発されました。→ [第10章](10-yaya-basics.md)、[第11章](11-yaya-practice.md)

## 五十音

### 相方（あいかた）

\1 側のキャラクターのこと。→「\0 側／\1 側」

### 当たり判定

シェルの画像の上で、ユーザーが触れられる範囲のこと。→「collision」

### イベント

ベースウェアが SHIORI に知らせる「出来事」。起動した（`OnBoot`）、1 秒たった（`OnSecondChange`）、マウスでなでられた、などがあり、それぞれ `On` で始まる名前がついています。ゴーストはイベントへの返事としてセリフを返します。→ [第7章](07-shiori-events.md)、[付録B](appendix-b-events.md)

### ウェイト

さくらスクリプトで、次の文字を表示するまで少し待たせること。会話の「間」を作るのに使います。`\_w[1000]`（1000 ミリ秒＝1 秒待つ）などのタグで指定します。→ [第6章](06-sakura-script.md)

### 伺か（うかがか）

デスクトップにキャラクターを表示して会話を楽しむデスクトップマスコットの一つ。現在では、互換ソフトの上で動くゴーストも含めた、ジャンルやコミュニティ全体を指す呼び名にもなっています。→ [第1章](01-what-is-ukagaka.md)

### エクスプローラ（SSP の）

SSP に内蔵された管理画面。インストール済みのゴースト・バルーン・シェル・ヘッドライン・プラグインを一覧し、切り替え・更新・削除などができます。右クリックメニューの「機能」から、または Ctrl+E で開きます。Windows のエクスプローラとは別物です。→ [第3章](03-ssp-features.md)

### 開発者用機能

SSP の本体設定「一般」でオンにできる、ゴースト制作者向けの機能群。スクリプトログや開発用パレットなどが使えるようになります。→ [第3章](03-ssp-features.md)、[第14章](14-debug.md)

### 開発用パレット

SSP の開発者用機能の一つ。当たり判定の表示やバルーンのテスト表示など、開発に便利なスイッチやツールをまとめたウィンドウです。→ [第14章](14-debug.md)

### 着せ替え

シェルの一部（服や小物など）を付けたり外したりして、見た目を変える仕組み。伺かでは MAYUNA と呼ばれ、SSP では右クリックメニューの「着せ替え」から切り替えられます（対応しているシェルのみ）。→ [第12章](12-shell.md)

### ゴースト

伺かのキャラクターデータ。とくに、何を話しどう反応するかを決める「心」の部分を指します。実際にはシェルとセットにして配布されたものを指すことがほとんどです。→ [第1章](01-what-is-ukagaka.md)、[第4章](04-ghost-structure.md)

### さくら側／うにゅう側

\0 側と \1 側の伝統的な呼び方。本家の伺かの最初のゴーストで、メインキャラクターが「さくら」、相方が「うにゅう」だったことに由来します。→「\0 側／\1 側」

### さくらスクリプト

ゴーストのセリフを書くための記法。文章の中に `\0`（話し手の切り替え）、`\s[0]`（表情の切り替え）、`\n`（改行）、`\e`（終わり）などの **タグ** を埋め込んで、表情や動きを指示します。→ [第6章](06-sakura-script.md)、[付録A](appendix-a-sakura-script.md)

### 里々（さとり）

SHIORI の一つ。会話文に近い書き方で、セリフを台本のように書けるのが特徴です。記号に全角文字を使います。プログラミング未経験の人に向いています。→ [第8章](08-satori-basics.md)、[第9章](09-satori-practice.md)

### シェル

ゴーストの見た目（立ち絵）のデータ。表情ごとの画像（サーフェス）と、`surfaces.txt` などの設定からなります。一つのゴーストが複数のシェルを持つことができ、切り替えると着替えたように見えます。→ [第12章](12-shell.md)

### 辞書

SHIORI が読み込む、セリフや処理を書いたファイル。里々では `dic` で始まり `.txt` で終わる名前のファイル（例：`dic_talk.txt`）、YAYA では拡張子が `.dic` のファイルを使います。→ [第8章](08-satori-basics.md)、[第10章](10-yaya-basics.md)

### スクリプトログ

SSP の開発者用機能の一つ。ゴーストが受け取ったさくらスクリプトの履歴を表示し、コピーや再実行ができます。エラーの履歴（エラーログ）にも切り替えられます。→ [第14章](14-debug.md)

### スコープ

さくらスクリプトで、今どのキャラクターが話しているかの状態。`\0` で \0 側、`\1` で \1 側のスコープに移ります。→ [第6章](06-sakura-script.md)

### タグ

さくらスクリプトの中で、表情の変更や改行などを指示する命令。`\` で始まります（例：`\s[0]`、`\n`）。→ [第6章](06-sakura-script.md)

### 追加シェル

ゴーストに最初から入っているシェル（`shell/master`）とは別に、あとから追加するシェル。たいてい特定のゴースト専用に作られ、そのゴーストにドロップしてインストールします。→ [第2章](02-install-ssp.md)、[第12章](12-shell.md)

### トーク

ゴーストが話す、ひとまとまりのセリフ。中身はさくらスクリプトで書かれています。→ [第6章](06-sakura-script.md)

### ネットワーク更新

インターネット経由でゴーストなどを最新版にする機能。変更されたファイルだけをダウンロードして上書きします。SSP ではゴーストのほか、シェル・バルーン・ヘッドライン・プラグインにも対応しています。→ [第2章](02-install-ssp.md)、[第15章](15-distribute.md)

### バルーン

ゴーストのセリフを表示する吹き出しのウィンドウ。ベースウェアに置かれ、すべてのゴーストで共有されます。→ [第2章](02-install-ssp.md)、[第13章](13-balloon.md)

### フリーシェル

ほかの人が自由に使えるように公開されているシェル素材。自分で絵を描かなくても、利用条件を守ればゴーストの見た目として使えます。→ [第12章](12-shell.md)

### プラグイン

ベースウェア全体に機能を追加する部品。どのゴーストを表示していても使えます。→ [第3章](03-ssp-features.md)

### ベースウェア

ゴーストを動かす土台となるソフトウェア。画面への表示やマウス操作の受け付け、SHIORI とのやりとりなどを受け持ちます。MATERIA、SSP、CROW などがあります。→ [第1章](01-what-is-ukagaka.md)

### ヘッドライン

Web サイトの更新情報を取ってきて、ゴーストに読み上げさせる機能。特定サイト用の部品は **ヘッドラインセンサ** と呼ばれます。SSP は RSS／Atom 形式にも対応しています。→ [第3章](03-ssp-features.md)

### 本体

\0 側のキャラクターのこと。→「\0 側／\1 側」

### ランダムトーク

ユーザーが何もしなくても、一定の間隔でゴーストが自分から話すトーク。どのくらいの間隔で話すかは、ゴーストの設定で決まります。→ [第7章](07-shiori-events.md)、[第8章](08-satori-basics.md)、[第10章](10-yaya-basics.md)

### readme（リードミー）

ゴーストなどに付属する説明書のファイル（`readme.txt`）。SSP では右クリックメニューの「情報」から開けます。→ [第2章](02-install-ssp.md)
