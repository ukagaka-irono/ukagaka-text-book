# 第13章 バルーンのしくみ

## この章で学ぶこと

- バルーンとは何か、シェルやゴーストとの関係
- バルーンのフォルダ構成と `descript.txt` の主な項目
- ゴーストの側からバルーンを指定する方法
- `\b` タグでバルーンを切り替える方法
- 自作するか、既存のバルーンを使うかの考え方

## バルーンとは

**バルーン** は、ゴーストのせりふを表示する吹き出しのウィンドウです。シェルが「体」なら、バルーンは「声の出口」にあたります。

シェルはゴーストの中（`hajimete/shell/`）に入っていますが、バルーンはちがいます。バルーンは SSP 全体で管理され、**すべてのゴーストで共有** されます。ユーザーは右クリックメニューの「バルーン」から、好きなバルーンに着せ替えられます。SSP には最初から「SSPデフォルト+」などのバルーンが入っています。

## バルーンのフォルダ構成

バルーンは、1つのフォルダに画像と設定ファイルをまとめたものです。主なファイルは次のとおりです。

```text
myballoon/
  descript.txt      … バルーンの設定
  balloons0.png     … \0 側の吹き出し（左向き）
  balloons1.png     … \0 側の吹き出し（右向き）
  balloonk0.png     … \1 側の吹き出し（左向き）
  balloonk1.png     … \1 側の吹き出し（右向き）
  balloonc0.png など … 文字を入力するボックス
  arrow0.png / arrow1.png … スクロール用の上・下矢印
  online0.png など  … 通信中に表示されるアニメーション
  sstp.png          … 外部からのメッセージ表示用のマーク
  readme.txt        … 説明（省略可）
  thumbnail.png     … 選択メニューの見本画像（省略可）
```

`balloons` が \0 側、`balloonk` が \1 側です。番号は **偶数が左向き、奇数が右向き** で、2枚1組になっています。一般には 0・1 が通常の吹き出し、2・3 が縦長の吹き出しという割り当てがよく使われますが、決まりではありません。`balloonk` を省略すると、同じ番号の `balloons` が使われます。

## descript.txt の主な項目

`myballoon/descript.txt`（一部）

```text
charset,UTF-8
type,balloon
name,はじめてのバルーン
craftman,yourname
craftmanw,あなたの名前

validrect.left,20
validrect.top,20
validrect.right,-20
validrect.bottom,-20

font.height,12
font.color.r,0
font.color.g,0
font.color.b,0
```

| 項目 | 意味 |
| --- | --- |
| `type` / `name` | `balloon` と、バルーンの名前 |
| `craftman` / `craftmanw` | 作者名 |
| `validrect.left` など | 文字を描いてよい範囲。マイナスの値は画像の右下からの距離になる（上の例は「四辺から 20 ピクセル内側」） |
| `origin.x` / `origin.y` | 文字を書き始める位置（ふつうは `validrect` に任せる） |
| `wordwrappoint.x` | 自動で折り返す位置 |
| `font.name` / `font.height` | フォント名と文字の高さ（ピクセル） |
| `font.color.r` / `.g` / `.b` | 文字の色（0〜255） |
| `arrow0.x` など | スクロール矢印の位置 |
| `homeurl` | SSP でのネットワーク更新用 URL |

バルーンの `descript.txt` は、ゴーストやシェルのものより設定項目がずっと多いのが特徴です。座標の細かい決まりは UKADOC の [Balloon設定](https://ukatech.shillest.net/ukadoc-spec/descript/balloon/) を見てください。`balloons0s.txt` のように、画像ごとに設定の一部だけを上書きするファイルも置けます（名前の最後の `s` に注意）。

## ゴーストの側からバルーンを指定する

バルーンはユーザーが選ぶものですが、ゴーストの `descript.txt` で「標準はこれ」と伝えられます。

`ghost/master/descript.txt`（追記）

```text
balloon,SSPデフォルト+
```

`balloon` には、標準で使ってほしいバルーンの名前（バルーンの `descript.txt` の `name`）を書きます。SSP には、これ以外に切り替えると強く警告する `recommended.balloon` もありますが、ユーザーの自由を狭めるので、本当に必要なときだけにしましょう。

バルーンの表示位置は、シェルの `descript.txt` の `sakura.balloon.offsetx` などで調整します（第12章）。

## `\b` でバルーンを切り替える

さくらスクリプトの `\b[番号]` を使うと、話している途中で吹き出しの種類を変えられます。

```text
\0\s[0]ふつうの吹き出しだよ。\x\b[2]長い話をするときは、こっちの大きな吹き出しにするね。\e
```

- 使える番号は 0 と偶数だけです。奇数は右向き用として予約されていて、左右は SSP が自動で選びます。
- `\b[-1]` でバルーンを隠せます。
- `\b2` のような書き方もありますが、こちらは 0〜9 しか使えません。

> **注意**
> バルーン2番がないバルーンもあります。たとえば「SSPデフォルト+」には \0 側の2番がありますが、ほかのバルーンにあるとは限りません。`\b[2]` を使うなら、推奨バルーンを指定するか、専用バルーンを同梱しましょう。

ゴーストからバルーンそのものを替えたいときは、SSP では `\![change,balloon,バルーン名]` が使えます。

## 自作か、既存のものを使うか

最初は **既存のバルーンを使う** のがおすすめです。「SSPデフォルト+」で十分に読みやすく、ゴースト作りに集中できます。ほかの人が作ったバルーンを標準にしたいなら、ゴーストの `descript.txt` の `balloon` にその名前を書いておきます。ゴーストに同梱して配るなら、そのバルーンの作者の許可や利用条件の確認が必要です。

ゴーストの雰囲気にぴったり合わせたくなったら **自作** に挑戦しましょう。既存のバルーンをまねて `balloons0.png` から順に描き、SSP の開発用パレットの「バルーンテストモード」で文字の範囲や矢印の位置を確かめながら調整します（第14章）。完成したバルーンは、ゴーストと一緒に配布（同梱）することもできます（第15章）。

## まとめ

- バルーンは吹き出しのウィンドウで、SSP 全体ですべてのゴーストが共有する。
- `balloons*.png` が \0 側、`balloonk*.png` が \1 側。偶数が左向き、奇数が右向き。
- バルーンの `descript.txt` は `type,balloon` と `name` のほか、文字の範囲やフォントを設定する。
- ゴーストの `descript.txt` の `balloon` で標準のバルーンを伝えられる。
- `\b[偶数]` で吹き出しの種類を切り替え、`\b[-1]` で隠す。

## 練習問題

1. `\b[3]` と書いても期待どおりに動かないのはなぜでしょう。
2. 自作バルーンで文字が吹き出しからはみ出します。まず見直すべき設定項目は何でしょう。

<details>
<summary>答えとヒント</summary>

1. 奇数の番号は右向き用に予約されていて、`\b` には 0 か偶数しか指定できないからです。左右は SSP が選びます。
2. 文字を描く範囲を決める `validrect.left` / `top` / `right` / `bottom` と、折り返し位置の `wordwrappoint.x` です。開発用パレットの「バルーンテストモード」で確かめましょう。

</details>
