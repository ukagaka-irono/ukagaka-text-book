# 第2章 SSP を入れて遊んでみよう

## この章で学ぶこと

- SSP を入手して、パソコンに置き、起動する方法
- ゴーストと遊ぶ基本操作と、右クリックメニューの見方
- nar ファイルをドラッグ＆ドロップして、新しいゴーストをインストールする方法
- ゴースト・シェル・バルーンの切り替えと、ネットワーク更新
- SSP の終わらせ方

## SSP を入手する

SSP は無料で使えるソフトウェア（フリーウェア）です。Windows で動きます。

最新版の SSP は、公式の配布ページ **SSP BUGTRAQ** で配布されています。

- SSP BUGTRAQ：<http://ssp.shillest.net/>

使い方の説明は、公式の **SSP ヘルプ** にまとまっています。この章で困ったら、あわせて読んでください。

- SSP ヘルプ：<https://ukatech.shillest.net/ukadoc-ssp/>

### パソコンに置く

SSP は、Windows によくある「インストーラで Program Files に入れる」タイプのソフトとは少し違い、**フォルダごと好きな場所に置いて使う** ソフトです。ゴーストや設定も、基本的にはそのフォルダの中に保存されます。

1. 配布ページから SSP の本体（フルセット）をダウンロードします。
2. ダウンロードしたファイルを実行するか解凍して、好きなフォルダに展開します。配布ファイルの形式や手順は時期によって変わることがあるので、配布ページの案内に従ってください。
3. 展開先のフォルダに `ssp.exe` があることを確かめます。

> **注意**
> SSP は自分のフォルダの中に設定やゴーストのデータを書き込みます。展開先は、ドキュメントフォルダの中など、自分のユーザーで自由に書き込める場所を選ぶと安心です。

## 起動する

1. 展開したフォルダの `ssp.exe` をダブルクリックします。
2. デスクトップにキャラクターと吹き出しが表示されたら、起動完了です。

最初に表示されるのは、SSP に標準で入っているゴースト **Emily/Phase4.5** です。猫耳の女性「エミリ」と、相方たちが登場します。

### ショートカットと自動起動

毎回フォルダを開くのが面倒なら、`ssp.exe` のショートカットをデスクトップなどに作っておきましょう。

パソコンの起動と同時に SSP を立ち上げたいときは、次のようにします。

1. エクスプローラ（Windows のファイル管理画面）を開き、アドレスバーをクリックします。
2. `shell:startup` と入力して Enter キーを押します。スタートアップフォルダが開きます。
3. そのフォルダの中に `ssp.exe` のショートカットを作ります。

## ゴーストと遊んでみる

ゴーストが何をできるかはゴーストごとに違いますが、多くのゴーストに共通する遊び方があります。Emily/Phase4.5 で試してみましょう。

| 操作 | 何が起きるか |
| --- | --- |
| しばらく放っておく | 自分から話し始める（ランダムトーク） |
| 頭のあたりでマウスを小刻みに動かす | 「なでる」反応をする |
| キャラクターをダブルクリック | 場所によっては「つつく」反応。何もない場所なら、ゴースト独自のメニューが出る |
| マウスホイールを回す | 「引っぱる」「めくる」など、ゴーストごとの反応 |
| キャラクターや吹き出しをドラッグ | 好きな位置に動かせる |

触れる場所の上では、マウスカーソルの形が変わることがあります。いろいろな場所を試してみてください。ゴースト独自の操作は、そのゴーストの説明書（readme）に書いてあることが多いです。

ドラッグで動かすと、画面の端やほかのキャラクターにぴったり並ぶように位置が調整されます。これが邪魔なときは、Ctrl キーを押しながら動かします。

## 右クリックメニュー

キャラクターを **右クリック** すると、SSP のメニューが開きます。SSP の操作のほとんどは、このメニューから行います。

メインキャラクター（\0 側）とサブキャラクター（\1 側）では、出てくるメニューが違います。サブキャラクターのメニューは項目が少ない省略版です。迷ったらメインキャラクターを右クリックしましょう。

おもな項目は次のとおりです。

| 項目 | できること |
| --- | --- |
| ネットワーク更新 | このゴーストを最新版に更新する |
| アンインストール | このゴーストを削除する（第3章） |
| RSS/ヘッドライン | Web サイトの更新情報を読み上げる（第3章） |
| プラグイン | インストール済みのプラグインを使う（第3章） |
| シェル倍率 | キャラクターを拡大・縮小する |
| 機能 | カレンダー、エクスプローラなどの機能を呼び出す |
| 設定 | SSP の本体設定などを開く（第3章） |
| ゴースト切り替え | 今のゴーストを別のゴーストに入れ替える |
| 他のゴーストを呼ぶ | 今のゴーストはそのままに、別のゴーストを追加で表示する |
| シェル | このゴーストの見た目（シェル）を切り替える |
| バルーン | このゴーストの吹き出しを切り替える |
| 最近使ったもの | 最近使ったゴーストなどをすぐ呼び出す |
| 情報 | SSP やゴーストの情報、説明書（readme）を見る |
| アイコン化 | ゴーストを最小化する |
| 終了／全て終了 | ゴーストや SSP を終わらせる |

> **注意**
> ゴーストによっては、メニューの項目名が独自の言葉に変わっていることがあります（並び順は同じです）。わかりにくいときは、本体設定の「ゴースト(1)」にある「ゴースト定義メニューを使わない」をオンにすると、標準の項目名で表示されます。

キャラクターが画面の外に出てしまっても大丈夫です。タスクバーの通知領域（タスクトレイ）にあるゴーストのアイコンを右クリックしても、同じメニューが開きます。

## ゴーストをインストールする

いよいよ、新しいゴーストを迎えてみましょう。

### nar ファイルとは

ゴーストは、ふつう **nar ファイル**（拡張子 `.nar`）という形で配布されています。nar は「Nanika ARchive」の略で、中身は zip 形式の圧縮ファイルの拡張子を変えたものです。ゴーストのほか、シェル、バルーン、プラグイン、ヘッドラインも、同じ nar 形式で配布されます。

### ゴーストを探す

ゴーストは、作者の Web サイトや、ゴーストを集めた検索サイト・アップローダで公開されています。SSP ヘルプの「リンク集」に、ゴーストやバルーンを探すのに役立つサイトが紹介されているので、そこから探してみましょう。

- SSP ヘルプ「リンク集」：<https://ukatech.shillest.net/ukadoc-ssp/about/links/>

ダウンロードする前に、配布ページの説明や利用条件をよく読んでください。

### ドラッグ＆ドロップでインストール

1. SSP を起動して、ゴーストを表示しておきます。
2. ダウンロードした `.nar` ファイルを、エクスプローラからキャラクターの上にドラッグ＆ドロップします。
3. ゴーストがインストールの開始や完了を知らせてくれます。利用条件の確認画面が出たときは、内容を読んでから進めてください。
4. インストールが終わったら、右クリックメニューの「ゴースト切り替え」を開き、新しいゴーストが一覧に増えていることを確かめます。

このほかにも、次のような方法があります。

- **ダブルクリックでインストール**：本体設定の「一般」にある「ファイルをSSPに関連付ける」をオンにすると、SSP の起動中に `.nar` ファイルをダブルクリックするだけでインストールできます（初期状態はオフです）。
- **URL からインストール**：ブラウザの nar ファイルへのリンクをキャラクターにドラッグ＆ドロップするか、右クリックメニューの「機能」→「アドレスバー」（Ctrl+Shift+U）に URL を入力すると、ダウンロードからインストールまでを SSP が行います。

> **注意**
> 追加シェルは、たいてい特定のゴースト専用に作られています。専用のゴーストではないゴーストにドロップすると、メッセージが出てインストールできません。追加シェルは、それを着せたいゴーストの上にドロップしましょう。

## ゴーストを切り替える・呼び出す

- **ゴースト切り替え**：右クリックメニューの「ゴースト切り替え」から選ぶと、今のゴーストが別のゴーストに入れ替わります。今と同じゴーストを選ぶと、そのゴーストを読み込み直します。
- **他のゴーストを呼ぶ**：右クリックメニューの「他のゴーストを呼ぶ」から選ぶと、今のゴーストを残したまま、もう一人のゴーストがデスクトップに現れます。複数のゴーストを同時に立たせる方法は、第3章でもう少し詳しく扱います。

## シェルとバルーンを切り替える

### シェル

右クリックメニューの「シェル」から、このゴーストにインストールされているシェルを選べます。シェルを替えると、見た目だけでなく、触れる場所やその反応が変わることもあります。追加シェルはゴーストの配布ページで一緒に公開されていることが多いので、気に入ったゴーストがいたら探してみましょう。

キャラクターが大きすぎる・小さすぎるときは、「シェル倍率」で拡大・縮小できます。

### バルーン

右クリックメニューの「バルーン」から、吹き出しのデザインを選べます。SSP には最初から「SSPデフォルト+」と「balloon for Emily/P4」の 2 種類が入っています。バルーンも nar ファイルをドロップして増やせます。

選んだバルーンは **ゴーストごとに記憶** されます。あるゴーストのバルーンを替えても、ほかのゴーストの吹き出しは変わりません。

## ネットワーク更新

ゴーストの作者がゴーストを改良したとき、配布ページから nar を落とし直さなくても、インターネット経由で最新版にできる仕組みがあります。これを **ネットワーク更新** といいます。変更されたファイルだけをダウンロードして上書きするので、手早く更新できます。

1. 更新したいゴーストを右クリックします。
2. 「ネットワーク更新」を選びます。
3. ゴーストが更新の確認を始め、新しいファイルがあればダウンロードして更新します。

ネットワーク更新に対応していないゴーストでは、この項目は選べません。

本体設定の「ゴースト(1)」にある「起動時の自動更新を有効にする」をオンにすると、設定した日数ごとに、ゴーストの起動後に自動で更新を確認してくれます。

SSP 本体の更新は、右クリックメニューの「機能」→「本体更新をチェック」で確認できます。更新をダウンロードし終えると、すべてのゴーストが自動で終了し、SSP が再起動するので注意してください。

## SSP を終了する

右クリックメニューの一番下に、終了のための項目が二つあります。

| 項目 | 動き |
| --- | --- |
| 終了 | メニューを出したゴーストだけを閉じる。最後の一人を閉じると SSP も終了する |
| 全て終了 | 表示中のすべてのゴーストを閉じて、SSP を終了する |

ゴーストを一時的に消したいだけなら、「アイコン化」で最小化する方法もあります。元に戻すには、タスクトレイのアイコンをダブルクリックします。

## まとめ

- SSP は公式の配布ページ SSP BUGTRAQ から入手し、フォルダごと好きな場所に置いて `ssp.exe` で起動します。
- SSP の操作の中心は、キャラクターを右クリックして開くメニューです。
- ゴーストやシェル、バルーンは nar ファイルで配布され、キャラクターにドラッグ＆ドロップするとインストールできます。
- 「ゴースト切り替え」で入れ替え、「他のゴーストを呼ぶ」で追加表示、「シェル」「バルーン」で見た目を替えられます。
- 対応しているゴーストは「ネットワーク更新」で最新版にできます。
- 「終了」は一人だけ、「全て終了」は SSP ごと終わらせます。

## 練習問題

1. 好きなゴーストを一つ探してインストールし、「ゴースト切り替え」で呼び出してみましょう。そのゴーストの readme はどこから開けるでしょうか。

<details>
<summary>ヒント</summary>

右クリックメニューの「情報」のサブメニューから、使用中のゴーストの readme を開けます。

</details>

2. nar ファイルの中身は、どんな形式のファイルでしょうか。

<details>
<summary>答え</summary>

zip 形式の圧縮ファイルです。拡張子が `.nar` に変えてあるだけなので、拡張子を `.zip` に戻せば一般的な解凍ソフトで中身を見られます。

</details>

3. ゴーストを二人同時に表示している状態で、片方だけを閉じたいときは、右クリックメニューのどの項目を使いますか。

<details>
<summary>答え</summary>

閉じたいゴーストを右クリックして「終了」を選びます。「全て終了」を選ぶと、両方とも閉じて SSP も終了します。

</details>
