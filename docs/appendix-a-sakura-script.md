# 付録A さくらスクリプト早見表

## この付録の使い方

よく使うさくらスクリプトのタグを、種類ごとに表にまとめました。くわしい説明と例は [第6章](06-sakura-script.md) にあります。ここにないタグや、オプションのくわしい指定は UKADOC の「さくらスクリプトリスト」で確かめてください（[付録D](appendix-d-links.md)）。

- 「対応」の列が「SSP」のものは、SSP 以外のベースウェアでは使えないことがあります。空欄のものは、本家 MATERIA と SSP の両方で使える古くからのタグです（ほかのベースウェアの対応状況は UKADOC を参照）。
- 例のサーフェス番号は「はじめてのゴースト」の割り当て（ことね：0 通常・1 照れ・2 驚き・5 笑顔、ぴーすけ：10 通常・11 別の表情）にそろえています。

## スコープ（話す人）

| タグ | 意味 | 対応 | 例 |
| --- | --- | --- | --- |
| `\0` / `\h` | \0 側（メインキャラクター）が話す | | `\0こんにちは。` |
| `\1` / `\u` | \1 側（サブキャラクター）が話す | | `\1オレもいるぴ。` |
| `\p[n]` | n 番目のキャラクターが話す（`\p[2]` で 3 人目） | SSP など | `\p[2]三人目です。` |

## サーフェス（表情・見た目）

| タグ | 意味 | 対応 | 例 |
| --- | --- | --- | --- |
| `\s[n]` | いまのスコープのキャラクターを n 番のサーフェスにする | | `\0\s[5]` |
| `\s[-1]` | いまのスコープのキャラクターを非表示にする | | `\1\s[-1]` |
| `\i[n]` | n 番のアニメーションを再生する | | `\i[1]` |
| `\i[n,wait]` | n 番のアニメーションが終わるまで待ってから先へ進む | SSP | `\i[1,wait]` |
| `\![bind,カテゴリ,パーツ,1または0]` | 着せ替えパーツを着る（1）・外す（0） | SSP など | `\![bind,頭,リボン,1]` |
| `\![set,alpha,0〜100]` | いまのスコープのキャラクターの透明度を変える（0 で透明） | SSP | `\![set,alpha,50]` |

## 表示制御（バルーンと文字）

| タグ | 意味 | 対応 | 例 |
| --- | --- | --- | --- |
| `\n` | 改行する | | `一行目\n二行目` |
| `\n[half]` | 半分の高さで改行する | | `\n\n[half]` |
| `\n[パーセント]` | 指定した割合の高さで改行する | SSP など | `\n[150]` |
| `\c` | いまのスコープのバルーンの文字を消す | | `\c` |
| `\C` | 先頭に書くと、直前のバルーンの文字の続きに書き足す | SSP など | `\C続きです。` |
| `\b[n]` | いまのスコープのバルーンを n 番にする（0 か偶数） | | `\b[2]` |
| `\b[-1]` | いまのスコープのバルーンを隠す | | `\b[-1]` |
| `\_l[x,y]` | 文字を書く位置を座標で動かす | | `\_l[0,0]` |
| `\_n` | 次の `\_n` まで自動改行しない | | `\_n長い一行\_n` |
| `\f[bold,1]` | 太字にする（`0` で戻す） | SSP など | `\f[bold,1]大事\f[bold,0]` |
| `\f[color,色]` | 文字の色を変える | SSP など | `\f[color,red]赤` |
| `\f[height,数値]` | 文字の大きさを変える | SSP など | `\f[height,+3]` |
| `\f[default]` | 文字の飾りをすべて元に戻す | SSP など | `\f[default]` |
| `\_b[ファイル,x,y]` | 画像をバルーンの指定位置に貼る | | `\_b[img\a.png,0,0]` |
| `\![set,balloontimeout,ミリ秒]` | 話し終わってからバルーンが閉じるまでの時間（0 か -1 で閉じない） | SSP | `\![set,balloontimeout,0]` |
| `\![set,balloonwait,倍率]` | 文字が流れる速さの倍率（1 で等倍、0 で一瞬） | SSP | `\![set,balloonwait,2]` |

## ウェイト・進行

| タグ | 意味 | 対応 | 例 |
| --- | --- | --- | --- |
| `\w1`〜`\w9` | 数字 × 50 ミリ秒待つ（1 けたのみ） | | `\w9` |
| `\_w[ミリ秒]` | 指定したミリ秒だけ待つ | SSP など | `\_w[1000]` |
| `\__w[ミリ秒]` | スクリプト開始（または `\x`）からの合計時間まで待つ | SSP | `\__w[3000]` |
| `\_q` | 次の `\_q` か `\e` まで、文字を一瞬で表示する | | `\_q一覧\_q` |
| `\x` | バルーンがクリックされるまで待つ | | `\x` |
| `\t` | 終わるまでマウスなどのイベントを受け付けない | | `\t` |
| `\_s` | 次の `\_s` まで、\0 側と \1 側が同時に話す | | `\_sせーの！\_s` |
| `\e` | スクリプトを終える | | `\e` |

## 選択肢

| タグ | 意味 | 対応 | 例 |
| --- | --- | --- | --- |
| `\q[表示,ID]` | 選択肢を出す。選ぶと `OnChoiceSelect`（Reference0 に ID）が起きる | | `\q[はい,yes]` |
| `\q[表示,OnXXX,r0,r1,...]` | 選ぶと `OnXXX` イベントが起きる。r0 以降は Reference0 以降に入る | | `\q[春,OnSeason,春]` |
| `\q[表示,script:スクリプト]` | 選ぶと、書いたさくらスクリプトを実行する | SSP | `\q[閉じる,script:\e]` |
| `\__q[ID,...]表示\__q` | 間にはさんだ部分を選択肢にする（自動改行あり） | SSP など | `\__q[OnTest]テスト\__q` |
| `\_a[ID]表示\_a` | 文中のリンク（アンカー）。クリックで `OnAnchorSelect` が起きる | | `\_a[help]ヘルプ\_a` |
| `\*` | このスクリプトの選択肢を時間切れにしない | | `\*` |
| `\![set,choicetimeout,ミリ秒]` | 選択肢の時間切れまでの時間（0 か -1 で時間切れなし） | | `\![set,choicetimeout,0]` |

## \! 系コマンド

| タグ | 意味 | 対応 | 例 |
| --- | --- | --- | --- |
| `\![raise,イベント名,r0,...]` | イベントを起こす | | `\![raise,OnNext,1]` |
| `\![notify,イベント名,r0,...]` | イベントを起こす（返事は使われない） | SSP | `\![notify,OnMemo]` |
| `\![timerraise,ミリ秒,繰り返し,イベント名,...]` | 指定時間後にイベントを起こす（繰り返しは 0 で繰り返す、1 以上で 1 回） | SSP | `\![timerraise,5000,1,OnLater]` |
| `\![embed,イベント名,r0,...]` | イベントの返事を、その場に埋め込んで続ける | SSP など | `\![embed,OnPart]` |
| `\![open,inputbox,ID,表示時間,初期文字]` | 文字入力の箱を開く。決定で `OnUserInput`（ID が `On` 始まりならその名前）が起きる | | `\![open,inputbox,OnName,0]` |
| `\![open,browser,URL]` | ブラウザで URL を開く | | `\![open,browser,https://example.com/]` |
| `\![change,ghost,ゴースト名]` | 指定したゴーストに交代する | | `\![change,ghost,random]` |
| `\![call,ghost,ゴースト名]` | 指定したゴーストを呼んで、同時に立たせる | SSP など | `\![call,ghost,random]` |
| `\![change,shell,シェル名]` | シェルを切り替える | SSP など | `\![change,shell,master]` |
| `\![set,windowstate,stayontop]` | いつも手前に表示する（`!stayontop` で解除） | | `\![set,windowstate,stayontop]` |
| `\![set,windowstate,minimize]` | 最小化する | | `\![set,windowstate,minimize]` |
| `\![updatebymyself]` | ネットワーク更新を始める | | `\![updatebymyself]` |
| `\![vanishbymyself]` | 確認なしで自分自身をアンインストールする（取り扱い注意） | | — |
| `\![sound,play,ファイル]` | 音声ファイルを鳴らす（オプション指定可） | SSP など | `\![sound,play,se\pon.wav]` |

## その他

| タグ | 意味 | 対応 | 例 |
| --- | --- | --- | --- |
| `\-` | ゴーストを終了する | | `またね。\-` |
| `\_v[ファイル]` | 音声ファイルを鳴らす（`ghost/master` からの相対パス） | | `\_v[se\pon.wav]` |
| `\_V` | `\_v` の再生が終わるまで待つ | | `\_V` |
| `\_?` | 次の `\_?` まで、タグを実行せずそのまま表示する | SSP | `\_?\n\_?` |
| `\\` | `\` という文字を表示する | | `\\` |
| `\%` | `%` という文字を表示する | | `100\%` |
| `\&[ID]` | 実体参照で記号を表示する（`\&[amp]` で `&`） | | `\&[amp]` |
| `%username` | ユーザー名に置き換わる（環境変数） | | `%username さん` |
| `%selfname` / `%keroname` | \0 側／\1 側の名前に置き換わる | | `%selfname だよ。` |
| `%month` / `%day` / `%hour` / `%minute` | いまの月・日・時・分に置き換わる | | `%month月%day日` |
