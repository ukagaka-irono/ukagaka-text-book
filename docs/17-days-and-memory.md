# 第17章 日付と記憶で会話を広げる

## この章で学ぶこと

- いまの日付・曜日・季節を読み取って、ランダムトークの中身を変える方法
- 出会った日を記録して日数を数え、誕生日やお正月などの記念日を祝う方法
- 何回かに分けて話す「続きもののトーク」の作り方
- ユーザーが話しかけた言葉や回数を覚えておき、あとで話題にする方法
- 入力された言葉にキーワードが含まれているかで、返事を変える方法

## この章で作るもの

ここまでで、ことねとぴーすけは時間帯であいさつを変え、メニューで操作できるようになりました。この章では「日付」と「記憶」を使って、毎日いっしょに過ごしている感じを出していきます。今日が何曜日か、出会ってから何日たったか、この前ユーザーが何を話してくれたか。こうしたことをゴーストが覚えていると、同じトークでもぐっと身近に感じられます。

新しい辞書を 1 つ作り、これまでの辞書に少しだけ書き足します。

| SHIORI | 新しく作るファイル | 書き足すファイル |
| --- | --- | --- |
| 里々 | `dic_days.txt` | `dic_menu.txt`（メニューと、話しかけを受け取る文） |
| YAYA | `dic_days.dic` | `yaya.txt`、`dic_talk.dic`（`OnAiTalk`）、`dic_menu.dic`（メニュー） |

里々は `dic` で始まり `.txt` で終わるファイルを自動で読み込むので（[第8章](08-satori-basics.md)）、`dic_days.txt` は置くだけで読み込まれます。YAYA は、`dic_days.dic` を作ってから `yaya.txt` の `dic` の行の最後に 1 行足します（[第11章](11-yaya-practice.md)）。

`ghost/master/yaya.txt`（追加部分）

```text
// ghost dictionaries (chapter 17)
dic, dic_days.dic
```

各節では、里々の書き方のあとに YAYA の書き方を並べています。自分が選んだ SHIORI のほうだけ読めば大丈夫です。完成形は [`samples/satori/hajimete/`](../samples/satori/hajimete/) と [`samples/yaya/hajimete/`](../samples/yaya/hajimete/) にあります。

> **注意**
> 里々のコードには、見えない **タブ文字** が入っている行があります（`＠名前` のあとに条件を書く行、`＞名前` のあとに条件を書く行、`＄名前` のあとに値を書く行）。[第9章](09-satori-practice.md) と同じく、半角スペースでは働きません。迷ったらサンプルのファイルを使ってください。

## いまの日時を読む

どちらの SHIORI にも、いまの日時を読むための名前が用意されています。

| 知りたいもの | 里々 | YAYA |
| --- | --- | --- |
| 年・月・日 | `（現在年）` `（現在月）` `（現在日）` | `year` `month` `day` |
| 曜日 | `（現在曜日）`（`日` `月` … `土` の 1 文字） | `weekday`（`0` が日曜日 … `6` が土曜日） |
| 時・分・秒 | `（現在時）` `（現在分）` `（現在秒）` | `hour` `minute` `second` |
| UNIX 時刻 | `（time_t）` | `GETSECCOUNT()` |

- 里々の名前は、数を **全角の数字** で返します。式の中では全角と半角は区別されないので、`（現在月）==12` のようにそのまま比べられます。
- YAYA の `year` などは、システム辞書が用意している変数です。`GETSECCOUNT` は YAYA の組み込み関数です。
- **UNIX 時刻** は、1970 年 1 月 1 日 0 時（世界標準時）から数えた秒数です。日付を 1 つの数で表せるので、「何日たったか」の計算に使います。YAYA の説明書では「EPOCH からの経過秒数」と呼ばれています。

## 曜日と季節で話を変える

### 里々：条件つきの単語群を使う

[第9章](09-satori-practice.md) の `＠時間のあいさつ` と同じように、単語群に **採用条件式** を付けて、曜日や月で中身を切り替えます。

`ghost/master/dic_days.txt`（曜日と季節の部分）

```text
＃ ---- 曜日のひとこと（採用条件式つきの単語群） ----
＠曜日のひとこと	（現在曜日）==月
一週間のはじまりだね。無理しないでいこう。
＠曜日のひとこと	(（現在曜日）==火)||(（現在曜日）==水)||(（現在曜日）==木)
週のまんなか。こつこつがんばろう。
＠曜日のひとこと	（現在曜日）==金
明日はお休みの人も多いかな。あとひと息！
＠曜日のひとこと	(（現在曜日）==土)||(（現在曜日）==日)
今日はお休み？　ゆっくりしてね。

＃ ---- 季節（月で決まる） ----
＠今の季節	(（現在月）>=3)&&(（現在月）<=5)
春
＠今の季節	(（現在月）>=6)&&(（現在月）<=8)
夏
＠今の季節	(（現在月）>=9)&&(（現在月）<=11)
秋
＠今の季節	(（現在月）==12)||(（現在月）<=2)
冬

＃ ---- 曜日と季節のランダムトーク ----
＊
：今日は（現在曜日）曜日。（曜日のひとこと）
：ことね、カレンダー係みたいだぴ。

＊
：もうすっかり（今の季節）だね。
：季節が変わるのは早いぴ。
```

- `（現在曜日）==月` は、`（現在曜日）` が展開されて `月==月` になり、成り立ちます。里々の `==` は文字列として比べるので、漢字どうしでも比べられます。
- 4 つの条件は重ならず、どの曜日（月）にも、どれか 1 つが必ず当てはまるようにしてあります。条件を書き足すときも、抜けや重なりがないように気をつけます。
- 名前のない `＊` を足したので、ランダムトークの候補が 2 つ増えます。

### YAYA：weekday と case を使う

YAYA では、`weekday` の数で `case` を使って分けます。季節のほうは、第11章で配列を使って月から季節を取り出す `季節のことば` と、それを使ったトークをすでに作りました。里々の `＠今の季節` は、それと同じことを単語群でしたものです。

`ghost/master/dic_days.dic`（曜日の部分）

```c
// 今日の曜日のトーク（OnAiTalk の候補）
曜日トーク
{
	_曜日 = ("日", "月", "火", "水", "木", "金", "土")
	_今日 = _曜日[weekday]
	"\1\s[10]\0\s[0]今日は%(_今日)曜日。\w9\n\n%(曜日のひとこと)\w9\1ことね、カレンダー係みたいだぴ。\e"
}

// 曜日で変わるひとこと（weekday は 0 が日曜日、6 が土曜日）
曜日のひとこと
{
	case weekday {
		when 1 {
			"一週間のはじまりだね。無理しないでいこう。"
		}
		when 2-4 {
			"週のまんなか。こつこつがんばろう。"
		}
		when 5 {
			"明日はお休みの人も多いかな。あとひと息！"
		}
		others {
			"今日はお休み？　ゆっくりしてね。"
		}
	}
}
```

作った関数は、`dic_talk.dic` の `OnAiTalk` の最後（第11章の夜ふかしの `if` のあと）に候補として足します。

`ghost/master/dic_talk.dic`（`OnAiTalk` の最後に追加）

```c
	//---- ここから第17章で追加（関数は dic_days.dic） ----

	// 曜日で変わる
	曜日トーク
```

`when 2-4` は「2 から 4 まで」、つまり火曜日から木曜日です。`others` には、残りの日曜日と土曜日が来ます。

## 記念日を祝う

### 考え方

記念日を祝うには、次の 3 つを用意します。

1. **出会った日を記録する。** まだ記録していなければ、今日の 0 時の UNIX 時刻を変数に入れます。変数は自動で保存されるので（第9章・第11章）、一度入れればずっと残ります。
2. **出会ってからの日数を数える。** 「今日の 0 時」から「出会った日の 0 時」を引いて、1 日の秒数 86400 で割ります。その前に半日分の 43200 を足しておくと、数秒のずれや夏時間で少し足りなくても、正しい日数に丸められます。
3. **1 分ごとに確かめる。** 記念日かどうかは、1 分ごとに届く `OnMinuteChange` で確かめます。起動した直後だけでなく、パソコンをつけたまま日付が変わったときにも気づけます。何度も祝わないように、祝った日の日数を `最後に祝った日` に覚えておきます。

`OnMinuteChange` の Reference は次のとおりです（[付録B](appendix-b-events.md)）。

| Reference | 中身 |
| --- | --- |
| 1 | キャラクターが画面から見切れているとき 1 |
| 2 | キャラクターどうしが重なっているとき 1 |
| 3 | いま話せるとき 1、話せないとき 0 |

話せないとき（ほかのトークの最中など）は、Reference3 が 0 になり、返したセリフは無視されます。そこで、Reference3 が 1 のときだけ祝うようにします。

### 里々

`ghost/master/dic_days.txt`（記念日の部分）

```text
＃ ---- 記念日（OnMinuteChange で1分ごとに確認する） ----
＊OnMinuteChange
＞出会った日を記録する	（変数「出会った日の秒」の存在）==0
＄知り合って何日＝(（time_t）-（現在時）*3600-（現在分）*60-（現在秒）-（出会った日の秒）+43200)/86400
＞記念日を選ぶ	(（Ｒ３）==1)&&(（最後に祝った日）!=（知り合って何日）)

＊出会った日を記録する
＄出会った日の秒＝（time_t）-（現在時）*3600-（現在分）*60-（現在秒）
＄最後に祝った日	-1

＊記念日を選ぶ
＞誕生日のあいさつ	(（現在月）==（誕生月）)&&(（現在日）==（誕生日）)
＞お正月のあいさつ	(（現在月）==1)&&(（現在日）==1)
＞百日ごとのあいさつ	(（知り合って何日）>0)&&(（知り合って何日）%100==0)

＊誕生日のあいさつ
＄最後に祝った日＝（知り合って何日）
：（5）（呼び名）、お誕生日おめでとう！
：おめでとうだぴ！　今日はごちそうだぴ！
：（1）生まれてきてくれて、ありがとう。

＊お正月のあいさつ
＄最後に祝った日＝（知り合って何日）
：（5）あけましておめでとう、（呼び名）！
：今年もよろしくだぴ。
：（現在年）年も、いっしょにおしゃべりしようね。

＊百日ごとのあいさつ
＄最後に祝った日＝（知り合って何日）
：（5）（呼び名）、今日で出会ってから（知り合って何日）日だよ。
：記念日だぴ！　お祝いするぴ！
```

- `（time_t）-（現在時）*3600-（現在分）*60-（現在秒）` が「今日の 0 時の UNIX 時刻」です。いまの秒数から、0 時から過ぎた分を引いています。
- `＞` は戻ってこないジャンプなので（第9章）、上の行ほど優先されます。誕生日とお正月が重なったら、誕生日を祝います。
- どの条件にも当てはまらなければ、`＊記念日を選ぶ` は何も話さずに終わります。`＊OnMinuteChange` が何も返さないときは、何も起きません。
- まだない変数（`（誕生月）` など）は、式の中では 0 になります。誕生日を教えてもらう前は、誕生日の条件は成り立ちません。
- `＄最後に祝った日` のあとはタブ文字で、`-1` という文字をそのまま入れています。出会った日（日数 0）に誕生日やお正月が来ても祝えるように、どの日数とも違う値にしてあります。

### YAYA

`ghost/master/dic_days.dic`（記念日の部分）

```c
// 1分ごとに届く（話せないときは reference[3] が 0 になって届く）
OnMinuteChange
{
	if ISVAR("出会った日の秒") == 0 {
		// はじめて届いたときに、今日を「出会った日」として記録する
		出会った日の秒 = GETSECCOUNT(year, month, day, 0, 0, 0, 0)
		最後に祝った日 = -1
	}
	elseif TOINT(reference[3]) == 1 {
		記念日のあいさつ
	}
}

// 出会った日から今日まで何日たったか（出会った日は 0）
出会ってからの日数
{
	(GETSECCOUNT(year, month, day, 0, 0, 0, 0) - 出会った日の秒 + 43200) / 86400
}

// 今日が記念日で、まだ祝っていなければ、お祝いのトークを返す
記念日のあいさつ
{
	_日数 = 出会ってからの日数
	if 最後に祝った日 != _日数 {
		if ISVAR("誕生月") && month == 誕生月 && day == 誕生日 {
			最後に祝った日 = _日数
			"\1\s[10]\0\s[5]ユーザーさん、お誕生日おめでとう！\w9\1おめでとうだぴ！　今日はごちそうだぴ！\w9\0\s[1]生まれてきてくれて、ありがとう。\e"
		}
		elseif month == 1 && day == 1 {
			最後に祝った日 = _日数
			"\1\s[10]\0\s[5]あけましておめでとう、ユーザーさん！\w9\1今年もよろしくだぴ。\w9\0%(year)年も、いっしょにおしゃべりしようね。\e"
		}
		elseif _日数 > 0 && _日数 % 100 == 0 {
			最後に祝った日 = _日数
			"\1\s[10]\0\s[5]ユーザーさん、今日で出会ってから%(_日数)日だよ。\w9\1記念日だぴ！　お祝いするぴ！\e"
		}
	}
}
```

- `GETSECCOUNT(年, 月, 日, 曜日, 時, 分, 秒)` は、指定した日時の UNIX 時刻を返します。4 番目の曜日は使われないので `0` を書きます。時・分・秒を 0 にすれば、その日の 0 時になります。
- `ISVAR("変数名")` は、変数があれば 0 以外、なければ 0 を返す組み込み関数です。
- `if`・`elseif` を 1 本につないでいるので、実行されるのは多くても 1 つのブロックだけです。上にあるものほど優先されます。
- どれにも当てはまらなければ、何も返しません。

### 誕生日を教えてもらう

ユーザーの誕生日は、メニューから教えてもらいます。月と日を選んでもらうので、文字を打つ入力ボックスではなく、つまみを動かして数を選ぶ **スライダーの入力ボックス** を使います。

```text
\![open,sliderinput,ID,表示時間,はじめの値,最小,最大]
```

これは SSP の機能です。表示時間を 0 にすると時間切れなしになり、ID を `On` で始めると、決定したときにその ID と同じ名前のイベントが届いて、Reference0 に選んだ数が入ります。ID の扱いは、文字を入力する `\![open,inputbox,…]`（里々は第9章、YAYA はこの章の後半）と同じです。

里々では、`dic_menu.txt` の `＊メニュー` の `＿呼び名を変える` の次に `＿誕生日を教える` の 1 行を足し、続きを `dic_days.txt` に書きます。

`ghost/master/dic_days.txt`（誕生日を教えてもらう部分）

```text
＊誕生日を教える
：（呼び名）の誕生日、教えてくれる？
：まずは何月生まれか、えらんでほしいぴ。
\![open,sliderinput,OnHajimeteBirthMonthInput,0,1,1,12]

＊OnHajimeteBirthMonthInput
＄誕生月の入力＝（Ｒ０）
：（誕生月の入力）月だね。
：じゃあ、何日生まれだぴ？
\![open,sliderinput,OnHajimeteBirthDayInput,0,1,1,31]

＊OnHajimeteBirthDayInput
＄誕生月＝（誕生月の入力）
＄誕生日＝（Ｒ０）
：（5）（誕生月）月（誕生日）日だね。覚えておくね！
：当日はお祝いするぴ！
```

月を選んだ時点では `誕生月の入力` に仮に入れておき、日まで選び終わってから `誕生月` と `誕生日` に入れています。途中で入力ボックスを閉じられても、半分だけ覚えた状態になりません。

YAYA では、`dic_menu.dic` の `メニュー` に選択肢を 2 つ足します（「話しかける」はこの章の後半で使います）。**選択肢の ID を `On` で始めると、`OnChoiceSelect` を通らずに、その ID と同じ名前のイベントが届きます**。第11章の `OnChoiceSelect` を書き換えなくてすみます。

`ghost/master/dic_menu.dic`（`メニュー` を書き換え）

```c
メニュー
{
	"\1\s[10]\0\s[0]なにかご用？\n\n/
	\q[おしゃべりして,menu_talk]\n/
	\q[話しかける,OnHajimeteTalk]\n/
	\q[誕生日を教える,OnHajimeteBirthday]\n/
	\q[トークの間隔を変える,menu_interval]\n/
	\q[なでてもらった回数,menu_count]\n/
	\q[なんでもない,menu_cancel]\e"
}
```

`ghost/master/dic_days.dic`（誕生日を教えてもらう部分）

```c
// メニューの「誕生日を教える」（\q の ID が On で始まるので、この名前のイベントが届く）
OnHajimeteBirthday
{
	"\1\s[10]\0\s[0]ユーザーさんの誕生日、教えてくれる？\w9\1まずは何月生まれか、えらんでほしいぴ。\![open,sliderinput,OnHajimeteBirthMonthInput,0,1,1,12]\e"
}

// 月が決まった（reference[0] にスライダーの値が入る）
OnHajimeteBirthMonthInput
{
	誕生月の入力 = TOINT(reference[0])
	"\0\s[0]%(誕生月の入力)月だね。\w9\1\s[10]じゃあ、何日生まれだぴ？\![open,sliderinput,OnHajimeteBirthDayInput,0,1,1,31]\e"
}

// 日が決まった
OnHajimeteBirthDayInput
{
	誕生月 = 誕生月の入力
	誕生日 = TOINT(reference[0])
	"\0\s[5]%(誕生月)月%(誕生日)日だね。覚えておくね！\w9\1\s[10]当日はお祝いするぴ！\e"
}
```

`reference[0]` は文字列で届くので、`TOINT` で数にしてから `month` や `day` と比べています。

## 続きもののトーク

ランダムトークを何回かに分けて、お話を少しずつ進めてみましょう。「どこまで話したか」を変数 `冒険の話の段階` に覚えておき、0 なら第1話、1 なら第2話……と話し分けます。変数は保存されるので、ゴーストを終了しても続きから話します。全部話し終えたあとは、ふつうのトークになります。

### 里々

`ghost/master/dic_days.txt`（続きもののトークの部分）

```text
＃ ---- 続きもののトーク（ぴーすけの冒険・全3話） ----
＃ 冒険の話の段階 に、どこまで話したかを覚えておきます。
＊
＞ぴーすけの冒険その１	（冒険の話の段階）==0
＞ぴーすけの冒険その２	（冒険の話の段階）==1
＞ぴーすけの冒険その３	（冒険の話の段階）==2
：ぴーすけ、冒険の話、もう一回して？
：何度も話すと照れるぴ……。

＊ぴーすけの冒険その１
＄冒険の話の段階＝1
（11）オレ、昔は大冒険をしたことがあるんだぴ。
：えっ、本当？　どこに行ったの？
：（10）それは……次のお楽しみだぴ。

＊ぴーすけの冒険その２
＄冒険の話の段階＝2
：ねえぴーすけ、冒険の続きを聞かせて！
：しかたないぴ。オレは窓から飛び出して、となりの家のベランダまで行ったんだぴ。
：となりの家って、すぐそこだよね？
：……続きはまた今度だぴ。

＊ぴーすけの冒険その３
＄冒険の話の段階＝3
：冒険の話、今日こそ最後まで聞かせてね。
：ベランダで、ひまわりの種をひとつぶ見つけたんだぴ。
：それで？
：（11）……それを食べて、帰ってきたぴ。おしまい。
：（2）それだけ！？
```

名前のない `＊` が選ばれると、段階に合った話へジャンプし、その話の中で段階を 1 つ進めます。ジャンプすると話し手は \1 側に戻るので、`＊ぴーすけの冒険その１` の最初の行は `：` なしでぴーすけのセリフになります。里々は選んだ文だけを実行するので、段階が進むのは、その話が選ばれたときだけです。

### YAYA

YAYA では、ひとつ気をつけることがあります。**関数の中の候補は、選ばれるかどうかに関係なく、すべて実行されてから 1 つが選ばれます。** `OnAiTalk` の候補の中で段階を進めると、別のトークが選ばれたときにも話が進んでしまいます。

そこで、段階を進める処理は、トークを最後まで話したときに起きるイベントで行います。さくらスクリプトの `\![notify,イベント名]` は、そこまで再生されたときに、自分のゴーストにイベントを届けます（SSP）。`\![raise,…]`（第10章）と違って、そのイベントで返したセリフは使われないので、話している最中のトークをじゃましません。

`ghost/master/dic_days.dic`（続きもののトークの部分）

```c
// OnAiTalk の候補。冒険の話の段階 に、どこまで話したかを覚えておく
//   段階を進める処理は、話し終えたときに届く OnHajimeteStoryNext で行う
続きもののトーク
{
	case TOINT(冒険の話の段階) {
		when 0 {
			"\0\s[0]\1\s[11]オレ、昔は大冒険をしたことがあるんだぴ。\w9\0えっ、本当？　どこに行ったの？\w9\1\s[10]それは……次のお楽しみだぴ。\![notify,OnHajimeteStoryNext]\e"
		}
		when 1 {
			"\1\s[10]\0\s[0]ねえぴーすけ、冒険の続きを聞かせて！\w9\1しかたないぴ。オレは窓から飛び出して、となりの家のベランダまで行ったんだぴ。\w9\0となりの家って、すぐそこだよね？\w9\1……続きはまた今度だぴ。\![notify,OnHajimeteStoryNext]\e"
		}
		when 2 {
			"\1\s[10]\0\s[0]冒険の話、今日こそ最後まで聞かせてね。\w9\1ベランダで、ひまわりの種をひとつぶ見つけたんだぴ。\w9\0それで？\w9\1\s[11]……それを食べて、帰ってきたぴ。おしまい。\w9\0\s[2]それだけ！？\![notify,OnHajimeteStoryNext]\e"
		}
		others {
			"\1\s[10]\0\s[0]ぴーすけ、冒険の話、もう一回して？\w9\1何度も話すと照れるぴ……。\e"
		}
	}
}

// 続きもののトークを最後まで話したときに届く（\![notify] で起こした通知なので、セリフは返さない）
OnHajimeteStoryNext
{
	冒険の話の段階 = TOINT(冒険の話の段階) + 1
}
```

`ghost/master/dic_talk.dic`（`OnAiTalk` に続けて追加）

```c
	// 続きもののトーク
	続きもののトーク
```

- まだ一度も代入していない `冒険の話の段階` は空なので、`TOINT` で 0 にしてから比べています。
- `\![notify,…]` は、トークの最後（`\e` の直前）に置きます。トークがそこまで再生されたときに、`OnHajimeteStoryNext` が届きます。

## ゴーストの記憶とキーワード

里々版では第9章で、メニューの「話しかける」から入力ボックスを開き、入力された言葉をそのまま繰り返しました。YAYA 版にはまだ「話しかける」がないので、ここで作ります。どちらも、次の 3 つができるようにします。

- 話しかけられた回数を数える
- 最後に話しかけられた言葉を覚える
- 言葉に決まった **キーワード**（「おはよう」「おなか」など）が含まれていたら、専用の返事をする

### 里々：言葉を覚えて、キーワードで返事を変える

`dic_menu.txt` の `＊OnHajimeteTalkInput` を、次のように書き換えます。増えたのは 2〜6 行目です。

`ghost/master/dic_menu.txt`（`＊OnHajimeteTalkInput` を書き換え）

```text
＊OnHajimeteTalkInput
＄話しかけた回数＝（話しかけた回数）+1
＄最後の話題	（Ｒ０）
＞おはようへの返事	（count、（Ｒ０）、おはよう）>0
＞おなかの話への返事	(（count、（Ｒ０）、おなか）>0)||(（count、（Ｒ０）、おやつ）>0)
＞つかれたへの返事	(（count、（Ｒ０）、つかれ）>0)||(（count、（Ｒ０）、疲れ）>0)
：「（Ｒ０）」かあ。（あいづち）
：ことね、ちゃんとわかってるぴ？
```

`（count、対象、探す文字列）` は、里々に入っている関数集 ssu の関数で、対象の中に探す文字列が何回出てくるかを返します。1 回以上なら、キーワードが含まれているということです。どのキーワードにも当たらなければ、第9章と同じあいづちになります。

`count` は **最後の引数だけ** が探す文字列で、それより前の引数はすべて対象として数えます。入力された言葉に `、` が入っていて、`（Ｒ０）` が展開されたあとに引数がいくつかに分かれても、全部の中から数えてくれるので、正しく判定できます。

> **コラム**
> 里々には、話しかけられた内容に合う文を探す「コミュニケート」というしくみもあります。文の名前に複数の語を並べておき、合う語の多い文を選ぶものです。ほかのゴーストとの会話にも使われます。くわしくは [里々の説明書の「コミュニケート」](https://ukatech.github.io/satori-docs/shiori/communicate/) を見てください。

キーワードごとの返事は `dic_days.txt` に書きます。

`ghost/master/dic_days.txt`（話しかけへの返事の部分）

```text
＃ ---- 話しかけへの返事（キーワードごと） ----
＊おはようへの返事
：（5）おはよう、（呼び名）！
：今日も一日、元気にいくぴ。

＊おなかの話への返事
＄おなかの話の回数＝（おなかの話の回数）+1
：（呼び名）、おなかすいてるの？
：食べ物の話は、これで（おなかの話の回数）回目だぴ。
：（5）じゃあ、（おやつ）でも食べよっか。

＊つかれたへの返事
：（1）（呼び名）、おつかれさま。
：少し休むといいぴ。オレが見張っててやるぴ。
```

`（おやつ）` は第8章の単語群です。おなかの話をした回数も、別の変数で数えています。

### YAYA：入力ボックスとキーワード

YAYA の章ではまだ入力ボックスを使っていないので、ここで紹介します。`\![open,inputbox,ID,表示時間]` で文字を入力する箱が開きます。表示時間を 0 にすると時間切れなしになります。SSP では、ID を `On` で始めると、決定したときにその ID と同じ名前のイベントが届き、`reference[0]` に入力された文字が入ります。

`ghost/master/dic_days.dic`（話しかけとキーワードの部分）

```c
// メニューの「話しかける」（\q の ID が On で始まるので、この名前のイベントが届く）
OnHajimeteTalk
{
	"\1\s[10]\0\s[0]なあに？　なんでも話してね。\![open,inputbox,OnHajimeteTalkInput,0]\e"
}

// 入力ボックスで決定された（reference[0] に入力された文字が入る）
OnHajimeteTalkInput
{
	_ことば = reference[0]
	if _ことば == "" {
		"\0\s[0]……あれ、何も書いてないよ？\e"
	}
	else {
		話しかけた回数 += 1
		最後の話題 = _ことば
		キーワードの返事(_ことば)
	}
}

// 言葉にキーワードが含まれているかで、返事を変える
キーワードの返事
{
	_ことば = _argv[0]
	if "おはよう" _in_ _ことば {
		"\0\s[5]おはよう、ユーザーさん！\w9\1\s[10]今日も一日、元気にいくぴ。\e"
	}
	elseif "おなか" _in_ _ことば || "おやつ" _in_ _ことば {
		おなかの話の回数 += 1
		"\0\s[0]ユーザーさん、おなかすいてるの？\w9\1\s[10]食べ物の話は、これで%(おなかの話の回数)回目だぴ。\e"
	}
	elseif "つかれ" _in_ _ことば || "疲れ" _in_ _ことば {
		"\0\s[1]ユーザーさん、おつかれさま。\w9\1\s[10]少し休むといいぴ。オレが見張っててやるぴ。\e"
	}
	else {
		"\0\s[0]「%(_ことば)」かあ。なるほどね。\w9\1\s[10]ことね、ちゃんとわかってるぴ？\e"
	}
}
```

- `"おなか" _in_ _ことば` は、`_ことば` の中に `おなか` が含まれていれば真になる演算子です。左に探す文字列、右に探される文字列を書きます。順番を逆にしないように注意してください。
- `キーワードの返事(_ことば)` のように、関数名のあとの `( )` に値を書くと、引数として渡せます。受け取る側では `_argv[0]` で読みます。
- 文字列の中の位置を知りたいときは、組み込み関数 `STRSTR(対象, 探す文字列, 探し始める位置)` も使えます。見つからなければ `-1` を返します。

### 覚えたことを話題にする

覚えた言葉と回数を、ランダムトークで思い出させます。まだ一度も話しかけられていないときは、話しかけるよう誘うトークにします。

`ghost/master/dic_days.txt`（思い出の部分）

```text
＃ ---- 覚えた話題を思い出すランダムトーク ----
＊
＞話題を思い出す	（変数「最後の話題」の存在）
：（呼び名）って、どんなことが好きなのかな。
：メニューの「話しかける」で教えてもらうといいぴ。

＊話題を思い出す
：そういえば（呼び名）、前に「（最後の話題）」って話してくれたよね。
：話しかけてもらったのは、ぜんぶで（話しかけた回数）回だぴ。
：（5）ちゃんと覚えてるんだから。
```

`ghost/master/dic_days.dic`（思い出の部分）

```c
// 覚えた話題を思い出すトーク（OnAiTalk の候補）
思い出トーク
{
	if 最後の話題 == "" {
		"\1\s[10]\0\s[0]ユーザーさんって、どんなことが好きなのかな。\w9\1メニューの「話しかける」で教えてもらうといいぴ。\e"
	}
	else {
		"\1\s[10]\0\s[0]そういえばユーザーさん、前に「%(最後の話題)」って話してくれたよね。\w9\1話しかけてもらったのは、ぜんぶで%(話しかけた回数)回だぴ。\w9\0\s[5]ちゃんと覚えてるんだから。\e"
	}
}
```

`ghost/master/dic_talk.dic`（`OnAiTalk` に続けて追加）

```c
	// 覚えた話題を思い出す
	思い出トーク
```

> **コラム：見切れと重なり**
> `OnMinuteChange` と、1 秒ごとに届く `OnSecondChange` では、Reference1 でキャラクターが画面の外にはみ出している（**見切れ**）か、Reference2 でことねとぴーすけが重なっている（**重なり**）かがわかります。たとえば Reference2 が 1 のときに「ぴーすけ、ちょっとどいて」と言わせることができます。なお里々は、見切れている間はランダムトークをしません。見切れていても話させたいときは、`＄見切れてても喋る＝有効` と書きます。

## 動かして確かめる

1. 辞書を保存し、ゴーストを読み込み直します。
2. 1 分ほど待ちます。最初の `OnMinuteChange` で出会った日が記録されます。
3. メニューの「誕生日を教える」で、**今日の日付** を選びます。1〜2 分のうちに誕生日のお祝いが始まれば成功です。同じ日にもう一度は祝わないことも確かめましょう。
4. 「話しかける」で「おなかすいた」「おはよう」などを入力して、返事が変わることを確かめます。
5. 里々は「なにか話して」、YAYA は「おしゃべりして」を何度か選び、曜日・季節・思い出・続きもののトークが出ることを確かめます。続きもののトークは、出るたびに話が進みます。

お正月や 100 日目は、その日まで待たなくても、条件の数を一時的に今日に合わせれば試せます（たとえば `==1` を今日の月や日に書き換える）。試したら元に戻してください。また、一度祝うと `最後に祝った日` に今日の日数が入るので、同じ日にもう一度試すときは、別の記念日の条件を使うか、ゴーストを終了してからセーブデータ（第9章・第11章）の `最後に祝った日` の行を消します。

開発用パレットの「現在時刻の仮想的変更」（[第14章](14-debug.md)）も、日時で変わる動作のテストに使えます。ただし、これは SSP が認識している日時を置き換える機能です。SHIORI が自分で読む日時（里々の `（現在月）` や YAYA の `month` など）に効かないように見えたら、上のように条件を書き換える方法で確かめてください。

## まとめ

- いまの日時は、里々なら `（現在年）` `（現在月）` `（現在曜日）` など、YAYA なら `year` `month` `weekday` などで読める。
- 曜日や季節は、里々なら条件つきの単語群、YAYA なら `case`（季節は第11章の配列）で話し分ける。
- 出会った日の 0 時を UNIX 時刻で記録しておけば、引き算と割り算で出会ってからの日数がわかる。日数を使えば「100 日ごと」の記念日も作れる。
- 記念日は `OnMinuteChange` で 1 分ごとに確かめる。話せるのは Reference3 が 1 のときだけ。祝った日を覚えておけば、同じ日に何度も祝わない。
- 続きもののトークは、段階を変数に覚えて話し分ける。YAYA では候補がすべて実行されるので、段階を進める処理は `\![notify,…]` で届くイベントで行う。
- 話しかけられた言葉や回数を変数に覚えると、あとで話題にできる。キーワードの判定は、里々なら `count`、YAYA なら `_in_` を使う。
- スライダーの入力ボックス `\![open,sliderinput,…]` や、ID が `On` で始まる選択肢を使うと、数の入力やメニューの続きを手軽に書ける（SSP）。

## 練習問題

1. 出会ってから何日たったかを話すランダムトークを書いてください。

   <details>
   <summary>ヒント</summary>

   里々では、`＊OnMinuteChange` が 1 分ごとに `＄知り合って何日` を計算し直しているので、名前のない `＊` の中で `（知り合って何日）` と書けば使えます。インストール直後で、まだ変数がないときのために、`＞文の名前`（タブ）`（変数「知り合って何日」の存在）` のようにジャンプで分けておくと安全です（この章の「覚えた話題を思い出す」トークと同じ形です）。YAYA では、`出会ってからの日数` を呼んでローカル変数に入れ、`OnAiTalk` には `if ISVAR("出会った日の秒") { … }` で、記録したあとだけ候補になるように足します。

   </details>

2. 12 月 25 日を記念日に加えて、クリスマスのお祝いを言わせてください。誕生日より優先度を低くします。

   <details>
   <summary>答えの例</summary>

   里々では、`＊記念日を選ぶ` の `＞誕生日のあいさつ` の行より下に次の行を足して、`＊クリスマスのあいさつ` を書きます（`＄最後に祝った日＝（知り合って何日）` の行を忘れずに）。

   ```text
   ＞クリスマスのあいさつ	(（現在月）==12)&&(（現在日）==25)
   ```

   YAYA では、`記念日のあいさつ` の誕生日の `if` のあとに `elseif month == 12 && day == 25 { … }` を足し、中で `最後に祝った日 = _日数` も忘れずに書きます。

   </details>

3. 話しかけた言葉に「ありがとう」が含まれていたら、ことねが照れる返事をするようにしてください。

   <details>
   <summary>ヒント</summary>

   里々では、`＊OnHajimeteTalkInput` に `＞ありがとうへの返事`（タブ）`（count、（Ｒ０）、ありがとう）>0` の行を足し、同じ名前の文を書きます。YAYA では、`キーワードの返事` に `elseif "ありがとう" _in_ _ことば { … }` を足します。表情は `（1）` や `\s[1]`（照れ）を使いましょう。

   </details>
