# 第6章 さくらスクリプト入門

## この章で学ぶこと

- さくらスクリプトとは何か、どうやって試すか
- 話す人の切り替え（`\0` `\1` `\p[n]`）と表情の切り替え（`\s[n]`）
- 改行・ウェイト・終了など、セリフの間（ま）を作るタグ
- 選択肢 `\q[表示,ID]` と、選んだあとに起きること
- `\![raise,...]` などの `\!` で始まるコマンドと、ゴーストを終了する `\-`

## さくらスクリプトとは

**さくらスクリプト** は、セリフの中に「ここで表情を変える」「ここで少し待つ」「ここから相方が話す」といった指示を埋め込むための書き方です。指示の部分は **タグ** と呼ばれ、必ず `\`（バックスラッシュ。日本語のキーボードでは `¥` キー）で始まります。

```text
\0\s[0]こんにちは、ユーザーさん。\w9\1\s[10]オレもいるぴ。\e
```

この 1 行で、次のことが起きます。

1. `\0` … ここから \0 側（ことね）が話す
2. `\s[0]` … ことねの表情を 0 番のサーフェスにする
3. 「こんにちは、ユーザーさん。」と表示する
4. `\w9` … 少し待つ
5. `\1` … ここから \1 側（ぴーすけ）が話す
6. `\s[10]` … ぴーすけの表情を 10 番にする
7. 「オレもいるぴ。」と表示する
8. `\e` … スクリプトをここで終わる

里々や YAYA で書いたセリフも、最終的にはすべてこのさくらスクリプトに変換されて SSP に渡されます（第7章）。SHIORI によっては一部のタグを自動で補ってくれますが、仕組みを知っておくと、思いどおりに動かないときに原因を探しやすくなります。

### SSP で試してみる

さくらスクリプトは、辞書を書かなくても SSP で直接試せます。

1. ゴーストを右クリックし、「設定」→「本体設定」を開きます。
2. 「一般」ページの **「開発者用機能を有効にする」** にチェックを入れて閉じます。
3. ゴーストをクリックしてから `Ctrl` + `S` を押すと、**スクリプト入力** の窓が開きます（開発用パレット〈`Ctrl` + `Shift` + `D`〉の「スクリプト入力」ボタンからも開けます）。
4. この章の例を貼り付けて実行すると、いま立っているゴーストがそのとおりに話します。

スクリプト入力に書けるのはさくらスクリプトそのものです。里々や YAYA の辞書の書き方は使えないので注意してください。

> **注意：サーフェス番号について**
> どの番号がどんな表情かは、シェルごとに作者が決めます。この本の「はじめてのゴースト」では、第12章で次のように割り当てます。
>
> | キャラクター | 番号と表情 |
> | --- | --- |
> | ことね（\0 側） | `\s[0]` 通常、`\s[1]` 照れ、`\s[2]` 驚き、`\s[5]` 笑顔 |
> | ぴーすけ（\1 側） | `\s[10]` 通常、`\s[11]` 別の表情 |
>
> ほかのゴーストで試すときは、そのゴーストにある番号に読み替えてください。存在しない番号を指定すると、うまく表示されないことがあります。

## 話す人を切り替える：スコープ

さくらスクリプトでは、「いまだれが話しているか」を **スコープ** と呼びます。

| タグ | 意味 |
| --- | --- |
| `\0` | \0 側（メインキャラクター）のスコープに移る。`\h` と書いても同じ |
| `\1` | \1 側（サブキャラクター）のスコープに移る。`\u` と書いても同じ |
| `\p[n]` | n 番目のキャラクターのスコープに移る。`\p[0]` は `\0`、`\p[1]` は `\1` と同じ（SSP など） |

スクリプトの最初は \0 側のスコープになっています。スコープを切り替えると、セリフはそのキャラクターのバルーンに表示されます。

```text
\0ねえぴーすけ、今日はいい天気だね。\1そうだぴ。お散歩日和だぴ。\0じゃあ一緒に行こっか！\e
```

`\p[2]` 以降を使うと、3 人目、4 人目のキャラクターも話せます。三人組のゴーストを作りたくなったら思い出してください。

## 表情を変える：サーフェス

| タグ | 意味 |
| --- | --- |
| `\s[n]` | いまのスコープのキャラクターを n 番のサーフェスにする |
| `\s[-1]` | いまのスコープのキャラクターを消す（非表示） |

`\s` は「いまのスコープのキャラクター」に効きます。だれの表情を変えるのかは、直前の `\0` や `\1` で決まります。

```text
\0\s[0]ユーザーさん、聞いて聞いて！\w9\s[5]クッキー焼いたんだ！\w9\1\s[11]……ちょっと焦げてるぴ。\w9\0\s[1]き、気のせいだよ！\e
```

ことねが `\s[0]`（通常）から `\s[5]`（笑顔）に表情を変え、そのあと `\1` でぴーすけに切り替わってから `\s[11]` を指定しています。最後はまた `\0` に戻って、ことねを `\s[1]`（照れ）にしています。もし `\1` を書かずに `\s[10]` を書くと、ことねの表情が 10 番になってしまいます。

> **コラム：番号の代わりに名前**
> `surfaces.txt` でサーフェスに別名をつけておくと、`\s[笑顔]` のように番号の代わりに名前で指定できます（第12章）。

## 文字の並べ方

| タグ | 意味 |
| --- | --- |
| `\n` | 改行する |
| `\n[half]` | 半分の高さで改行する |
| `\n[パーセント]` | 指定した割合の高さで改行する（`\n[150]` で 1 行半）（SSP など） |
| `\c` | いまのスコープのバルーンの文字を消す |
| `\b[n]` | いまのスコープのバルーンを n 番に変える。`\b[-1]` でバルーンを隠す |

バルーンの幅を超えた文字は自動で折り返されますが、区切りのよいところで `\n` を入れると読みやすくなります。`\n\n[half]` のように 1 行半あけると、段落の区切りのように見せられます。

```text
\0今日の予定はね、\nお買い物と、\nお散歩と、\nお昼寝！\n\n[half]\1全部ゆるいぴ……。\e
```

`\c` は、話の途中で場面を変えたいときに使います。

```text
\0むかしむかし、あるところに……\w9\w9\c\s[5]……って、もう眠いからまた明日ね！\e
```

`\b[n]` で使えるバルーンの番号は、バルーンによって違います。番号は 0 か偶数です（奇数はキャラクターの右側に出すバルーン用に予約されています）。存在しない番号を指定したときの見え方はバルーン次第なので、使うときは推奨バルーンを指定するなどの工夫が必要です（第13章）。

## 間（ま）を作る：ウェイト

文字が一気に出ると、会話のテンポが感じられません。**ウェイト** を入れて、間を作りましょう。

| タグ | 意味 |
| --- | --- |
| `\w1`〜`\w9` | 数字 × 50 ミリ秒待つ（`\w9` で 0.45 秒） |
| `\_w[ミリ秒]` | 指定したミリ秒だけ待つ（`\_w[1000]` で 1 秒）（SSP など） |
| `\_q` | 次の `\_q` か `\e` まで、文字を待たずに一瞬で表示する |
| `\x` | ユーザーがバルーンをクリックするまで待つ |

`\w` に書けるのは 1 〜 9 の 1 けただけです。`\w10` と書くと「`\w1` のあとに文字の `0`」と読まれてしまうので、長く待ちたいときは `\w9\w9` のように重ねるか、`\_w[1000]` を使います。

```text
\0ぴーすけ、あのね。\w9\w9\w9\1……なんだぴ。\_w[1500]\0やっぱりなんでもない！\e
```

`\_q` で囲んだ部分は、ウェイトなしで一度に表示されます。表や一覧を見せたいときに便利です。ただし、`\w` などのウェイトのタグは `\_q` の中でもちゃんと待ちます。里々のように、セリフに自動でウェイトを入れてくれる SHIORI を使うときは、`\_q` の中でもそのウェイトがかかることに注意しましょう（UKADOC でも注意されています）。

```text
\0今日のおやつ候補：\n\_q・クッキー\n・ケーキ\n・おせんべい\_q\n\nどれにしよう？\e
```

## スクリプトの終わり：\e

| タグ | 意味 |
| --- | --- |
| `\e` | スクリプトを終える。これより後ろに書いたものは表示も実行もされない |

`\e` はスクリプトの終わりのしるしです。いくつかのタグの効果も、ここで終わります。この本の例では、最後にかならず `\e` をつけています。

## 選択肢

ゴーストからユーザーに質問して、答えを選んでもらうこともできます。

| タグ | 意味 |
| --- | --- |
| `\q[表示,ID]` | 選択肢を出す。選ばれると、ID を知らせるイベントが起きる |
| `\q[表示,OnXXX,r0,r1,...]` | ID が `On` で始まると、そのままその名前のイベントが起きる。後ろの値は Reference0 以降に入る |
| `\*` | このスクリプトの選択肢を時間切れにしない |

```text
\0ユーザーさん、おやつは何がいい？\n\n\q[クッキー,cookie]\n\q[ケーキ,cake]\n\q[なんでもいい,any]\e
```

`\q` の選択肢は自動では改行されないので、1 つずつ `\n` で区切っています。

### 選んだあとに起きること

選択肢を選ぶと、SSP から SHIORI へ **イベント** が届きます。

- `\q[クッキー,cookie]` を選ぶと、**`OnChoiceSelect`** というイベントが起き、その Reference0 に `cookie` が入ります。SSP では、それより先に **`OnChoiceSelectEx`** が起き、こちらには Reference0 に表示の文字（クッキー）、Reference1 に ID（cookie）が入ります。
- ID を `On` で始めると、`OnChoiceSelect` の代わりに、その名前のイベントがそのまま起きます。

```text
\0ぴーすけはどっちが好き？\n\n\q[ひまわりの種,OnOyatsuPeesuke,ひまわり]\n\q[パンくず,OnOyatsuPeesuke,パン]\e
```

この例では、どちらを選んでも `OnOyatsuPeesuke` というイベントが起き、Reference0 に `ひまわり` か `パン` が入ります。同じ種類の質問をまとめて一つのイベントで受け取れるので、整理しやすい書き方です。

イベントや Reference の意味は第7章で、選ばれたあとの返事を辞書にどう書くかは第8章（里々）・第10章（YAYA）で説明します。

選択肢は、しばらく放っておくと時間切れで消えます。じっくり考えてほしい質問には、スクリプトのどこかに `\*` を書いておきましょう。

> **コラム：選択肢の中でスクリプトを実行する**
> SSP では `\q[閉じる,script:\e]` のように、ID の代わりに `script:` に続けてさくらスクリプトを書くと、選んだときにそれをそのまま実行できます。

## \! で始まるコマンド

`\!` で始まるタグは、表示以外のいろいろな動作を SSP に頼むためのものです。数がとても多いので、ここでは代表的なものだけ紹介します。

| タグ | 意味 |
| --- | --- |
| `\![raise,イベント名,r0,r1,...]` | 指定したイベントを起こす。後ろの値は Reference0 以降に入る |
| `\![open,inputbox,ID,表示時間,初期テキスト]` | 文字を入力してもらう箱を開く。決定すると `OnUserInput` イベントが起きる |
| `\![open,browser,URL]` | 本体設定で選んだブラウザで URL を開く |
| `\![set,balloontimeout,ミリ秒]` | 話し終わってからバルーンが閉じるまでの時間を決める（SSP）。0 か -1 で閉じない |
| `\![change,ghost,ゴースト名]` | 指定したゴーストに交代する |

`\![raise,...]` は、一つのセリフから別のセリフへつなぐときによく使います。

```text
\0そうだ、ぴーすけに聞きたいことがあったんだ。\w9\![raise,OnAskPeesuke,おやつ]\e
```

これを実行すると、話し終えたところで `OnAskPeesuke` というイベントが起き、Reference0 に `おやつ` が入ります。続きのセリフは、SHIORI 側で `OnAskPeesuke` に書いておきます。

文字を入力してもらう例です。表示時間はミリ秒で、0 以下にすると時間切れなしになります。

```text
\0ユーザーさんのことを、なんて呼べばいい？\![open,inputbox,OnNameInput,0]\e
```

ID を `On` で始めているので、決定すると `OnNameInput` イベントが起き、入力された文字が Reference0 に入ります（`On` で始まらない ID のときは `OnUserInput` が起き、Reference0 に ID、Reference1 に入力内容が入ります）。

## ゴーストを終了する：\-

| タグ | 意味 |
| --- | --- |
| `\-` | ゴーストを終了する。SSP で複数のゴーストを立てているときは、実行したゴーストだけが終わる |

終了のあいさつ（`OnClose` イベントの返事）の最後に `\-` を置くと、あいさつを言い終えてからゴーストが終了します。

```text
\0\s[0]今日もありがとう、ユーザーさん。\w9\1\s[10]またなぴ。\w9\w9\-\e
```

> **注意**
> スクリプト入力でこの例を試すと、本当にゴーストが終了します。SSP の開発用パレットにある「`\-`タグで終了しない」をオンにすると、`\-` を無視して試せます。

## 文字としての \ を書くには

`\` そのものをセリフに出したいときは `\\` と書きます。同じように、`%` で始まる言葉（`%username` などの **環境変数**。SSP がユーザー名などに置き換えます）を文字のまま出したいときは `\%` と書きます。`[ ]` の中の引数で `]` を使いたいときは `\]` と書きます。

```text
\0お金の記号は \\ だよ。\n%username さん、覚えた？\e
```

## まとめ

- さくらスクリプトは、セリフに `\` で始まるタグを埋め込んで、話者・表情・間などを指示する書き方です。
- `\0` `\1` `\p[n]` でスコープ（話す人）を、`\s[n]` でいまのスコープの表情を切り替えます。
- `\n` `\n[half]` で改行、`\c` で消去、`\b[n]` でバルーン切り替え、`\w1`〜`\w9` と `\_w[ミリ秒]` で間を作り、`\_q` で一気に表示します。
- `\q[表示,ID]` で選択肢を出すと、選ばれたときに `OnChoiceSelect`（ID が `On` で始まればその名前）のイベントが起きます。
- `\![raise,...]` などの `\!` コマンドで SSP にいろいろな動作を頼めます。`\e` でスクリプトを終え、`\-` でゴーストを終了します。

## 練習問題

1. 次のセリフをさくらスクリプトにしてください。ことね（表情 0）「ねえ、ぴーすけ」→ 少し待つ → ぴーすけ（表情 10）「なんだぴ」→ スクリプト終了。

<details>
<summary>答えの例</summary>

```text
\0\s[0]ねえ、ぴーすけ。\w9\1\s[10]なんだぴ。\e
```

</details>

2. 次のスクリプトを実行したら、ぴーすけではなくことねの表情が変わってしまいました。どこがまちがっているでしょうか。

```text
\0\s[0]ぴーすけ、怒ってる？\w9\s[10]怒ってないぴ。\e
```

<details>
<summary>答え</summary>

`\s[10]` の前に `\1` がないので、スコープが \0 側のままです。`\w9\1\s[10]怒ってないぴ。` のように、`\1` でスコープを切り替えてから `\s[10]` を書きます。

</details>

3. 「好きな季節は？」と聞き、春・夏・秋・冬の 4 つの選択肢を出して、どれを選んでも `OnSeason` イベントが起き、Reference0 に季節名が入るようにしてください。

<details>
<summary>答えの例</summary>

```text
\0好きな季節は？\n\n\q[春,OnSeason,春]\n\q[夏,OnSeason,夏]\n\q[秋,OnSeason,秋]\n\q[冬,OnSeason,冬]\e
```

</details>

4. 1 秒待ちたくて `\w20` と書きましたが、思ったように動きません。なぜでしょうか。どう書けばよいでしょうか。

<details>
<summary>答え</summary>

`\w` の後ろに書ける数字は 1 けた（1〜9）だけなので、`\w2` のあとに文字の `0` が表示されてしまいます。1 秒待つには `\_w[1000]` と書くか、`\w9\w9\w2`（450＋450＋100 ミリ秒）のように重ねます。

</details>
