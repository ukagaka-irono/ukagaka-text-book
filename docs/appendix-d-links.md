# 付録D 参考資料とリンク

## この付録の使い方

- 伺か・SSP の公式資料がどこにあるか
- 仕様（UKADOC）・SSP の使い方（SSP ヘルプ）・SHIORI のマニュアルの使い分け
- この本の各章と、公式資料の対応

この本は入門書なので、すべての仕様を載せてはいません。もっと詳しく知りたくなったら、ここに挙げる公式資料を読んでください。リンク先の内容は更新されることがあるので、この本と食い違うときは公式資料のほうを優先してください。

## 資料の選び方

> **コラム：UKADOC の読み方**
> さくらスクリプトリストや SHIORI Eventリストは、とても長い一覧です。ブラウザのページ内検索（Ctrl+F）で、タグ名（`\s` など）やイベント名（`OnBoot` など）を探すのが早道です。各項目の「対応」欄に `SSP` があれば、SSP で使えます。
