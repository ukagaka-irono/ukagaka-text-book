# 第3章 SSP をもっと使いこなす

## この章で学ぶこと

- 本体設定の開き方と、よく使う設定項目
- エクスプローラで、たくさんのゴーストやバルーンを管理する方法
- ヘッドライン（RSS）とプラグインの使い方
- 複数のゴーストを同時に立たせる方法と、ゴーストのアンインストール
- 困ったときの対処と、ゴースト制作で使う開発者用機能のあらまし

## 本体設定

SSP 全体の設定は **本体設定** というダイアログで行います。

1. キャラクターを右クリックします。
2. 「設定」→「本体設定」を選びます。
3. 設定は「一般」「ゴースト(1)」「表示」などのページに分かれています。見たいページを選ぶと、その設定が表示されます。

各ページのダイアログ右上の「？」を押すと、そのページの SSP ヘルプが開きます。

### よく使う設定項目

本体設定はたくさんのページに分かれていますが、遊ぶうえでまず知っておきたいのは次の項目です。基本的には初期状態のままで問題なく使えます。

| ページ | 項目 | 内容 |
| --- | --- | --- |
| 一般 | ファイルをSSPに関連付ける | オンにすると、nar ファイルのダブルクリックでインストールできる（初期状態はオフ） |
| 一般 | SSPが更新されているか自動でチェックする | SSP 本体の更新を自動で確認する |
| 一般 | ユーザ情報 | 名前・呼ばれ方・誕生日などを登録する。対応しているゴーストは、話の中で使ってくれることがある |
| 一般 | 開発者用機能を有効にする | ゴースト制作用の機能を出す。遊ぶだけならオフのまま（後述） |
| ゴースト(1) | ゴーストを1つランダムに選択して起動／ゴーストを起動時に選択する | SSP 起動時に、ランダムなゴーストで起動するか、選択画面から選んで起動するかを決める（どちらもオフなら前回のゴーストで起動） |
| ゴースト(1) | 起動時の自動更新を有効にする | 設定した日数ごとに、ゴーストのネットワーク更新を自動で確認する |
| ゴースト(2) | 常に手前に表示 | ゴーストを常にほかのウィンドウより手前に出す |
| ゴースト(2) | シェル共通倍率設定 | 全ゴーストの表示倍率をまとめて決める |
| 喋り/バルーン | メッセージスピード | 文字が表示される速さ |
| 喋り/バルーン | 喋りタイムアウト | 話し終わってから吹き出しが自動で閉じるまでの時間 |
| 接続(2) | ヘッドライン「自動的にチェック」 | ヘッドラインを一定時間ごとに自動で読み上げる |
| 国際化 | 省略時の文字コード | 文字化けしたときに調整する（通常は Default のまま） |

### ゴーストごとの設定

「常に手前に表示」や「サウンドを鳴らさない」などは、ゴーストごとに変えることもできます。右クリックメニューの「設定」→「ゴーストごとの設定」を開いてください。ここでの設定は、本体設定の「ゴースト(2)」より優先されます。

## エクスプローラで管理する

ゴーストが増えてくると、右クリックメニューから探すのが大変になります。そんなときは SSP の **エクスプローラ** を使いましょう。Windows のエクスプローラとは別の、SSP 内蔵の管理画面です。

1. 右クリックメニューの「機能」→「エクスプローラ」を選びます（Ctrl+E でも開けます）。
2. インストール済みのゴーストが一覧で表示されます。上部の「種類」メニューで、バルーン・シェル・ヘッドライン・プラグインの一覧に切り替えられます。
3. 項目を選んで右クリックすると、次のような操作ができます。

| 操作 | 内容 |
| --- | --- |
| 切り替え／ゴーストを呼ぶ | ゴーストを切り替える、または追加で表示する |
| ネットワーク更新 | ゴーストを起動せずに更新する |
| READMEを開く | 説明書を開く |
| 配布元URLを開く | 配布ページをブラウザで開く |
| フォルダを開く | そのゴーストのファイルが入っているフォルダを開く |
| 削除 | アンインストールする |

一覧の見出し（名前、作者名など）をクリックすると並べ替えができ、「編集」メニューには検索もあります。

> **コラム：まとめてネットワーク更新**
> エクスプローラで一覧を選択した状態で Ctrl+A を押すと全項目を選択できます。そのまま右クリックして「ネットワーク更新」を選べば、インストールしているゴーストをまとめて更新できます。数が多いと時間がかかるので、時間に余裕があるときに試しましょう。

## ヘッドライン（RSS）

**ヘッドライン** は、Web サイトの更新情報を取ってきて、ゴーストに読み上げてもらう機能です。SSP は、ブログなどでよく使われる RSS や Atom 形式の更新情報（フィード）にも対応しています。

### 読み上げてもらう

1. 右クリックメニューの「RSS/ヘッドライン」を開きます。
2. 読み上げてほしいサイトを選びます。
3. ゴーストが更新情報を話してくれます。

SSP には、最初からいくつかのヘッドラインが入っています。初期状態では自動巡回はオフです。定期的に読み上げてほしいときは、本体設定の「接続(2)」で「自動的にチェック」をオンにし、間隔を分単位で設定します。

### 追加する

- **ヘッドラインセンサ**（特定のサイト用の部品）は、nar ファイルをゴーストにドロップしてインストールします。
- **RSS に対応したサイト** は、サイトの URL や RSS のアイコンを、ブラウザからキャラクターにドラッグ＆ドロップするだけで追加できます。右クリックメニューの「機能」→「アドレスバー」に URL を入力する方法もあります。

## プラグイン

**プラグイン** は、SSP に機能を追加する部品です。どのゴーストを表示しているときでも使えます。

1. 配布されているプラグインの nar ファイルを、キャラクターにドラッグ＆ドロップしてインストールします。
2. 右クリックメニューの「プラグイン」を開くと、インストールしたプラグインが並んでいます。
3. 選ぶと、プラグインの機能が実行されたり、設定画面が開いたりします。何が起きるかはプラグインによって違います。

使わなくなったプラグインは、エクスプローラの種類を「プラグイン」にして、右クリックの「有効/無効」で無効にできます。

## 複数のゴーストを同時に立たせる

SSP は、一つの SSP の中で何人ものゴーストを同時に表示できます。

1. 一人目のゴーストを右クリックし、「他のゴーストを呼ぶ」から二人目を選びます。
2. 二人目のゴーストがデスクトップに現れます。重ならないように、ドラッグで位置を調整しましょう。
3. 閉じるときは、閉じたいゴーストを右クリックして「終了」を選びます。「全て終了」を選ぶと全員が閉じます。

ゴースト同士が話しかけ合うこともあります。どんな組み合わせで反応があるかは、ゴースト次第です。

「全て終了」で終わらせた場合、次に SSP を起動したときに、閉じたときのゴーストたちがそろって起動します（本体設定の「ゴースト(1)」の起動設定によります）。

> **注意**
> ゴーストをたくさん同時に立たせると、そのぶんパソコンへの負担が増えます。動きが重いと感じたら、人数を減らしてみてください。

## ゴーストをアンインストールする

もう使わないゴーストは、アンインストールできます。

1. 消したいゴーストを右クリックします。
2. 「アンインストール」を選びます。
3. 確認のダイアログが出るので、内容を確かめてから進めます。

ゴーストによっては、アンインストールのメニューが表示されないことがあります。その場合は、本体設定の「一般」で「常にアンインストールメニューを表示」をオンにするか、エクスプローラで対象を選んで右クリックの「削除」を使います。

> **注意**
> アンインストールすると、そのゴーストのファイルが削除されます。取り消しはできないものと考えて、会話の記録などを残しておきたいゴーストは、先にエクスプローラの「フォルダを開く」でフォルダの場所を確かめ、必要ならフォルダごとバックアップしておきましょう。

## 困ったときは

よくあるトラブルと対処を表にまとめました。詳しくは SSP ヘルプの「よくある質問」も見てください。

| 症状 | 対処 |
| --- | --- |
| キャラクターや吹き出しが画面の外に行ってしまった | タスクトレイのアイコンを右クリックしてメニューを開き、「機能」→「シェル位置初期化」（Ctrl+Shift+F12）または「バルーン位置初期化」（Ctrl+Shift+F10）を選ぶ |
| ゴーストがしゃべらなくなった | 画面の端からはみ出していると話さないゴーストがあるので、余裕を持たせた位置に動かす |
| 表情やトークの様子がおかしい | 右クリックメニューの「設定」で「旧仕様サポート」がオンになっていたらオフにする |
| 古いゴーストが話さない | 右クリックメニューの「設定」で「旧仕様サポート」をオンにする、または「話すタイミングをゴーストまかせ」をオフにすると話すようになることがある |
| 文字化けする | 右クリックメニューの「設定」→「文字コード設定」、または本体設定の「国際化」の「省略時の文字コード」を調整する。日本語版以外の Windows では「国際化」のフォント設定も試す |
| ネットワーク更新で MD5 が合わないと言われる | ウイルス対策ソフトやファイアウォールを一時的に止めて試す。直らなければゴーストの作者に知らせる |
| 特定のゴーストに切り替えたら SSP が起動しなくなった | SSP のフォルダの `data\profile\app.dat` が設定ファイル。これを削除するか、問題のゴーストのフォルダを `ghost` フォルダの外へ一時的に移動すると、標準のゴーストで起動できる |
| ゴーストが見つからない（メニューに出ない） | 右クリックメニューの「機能」→「動作情報再読み込み」で、フォルダの中身を読み込み直す |

> **注意**
> `app.dat` を削除すると、SSP の設定が初期状態に戻ります。削除する前に、別の場所へコピーしておくと安心です。

## 制作に向けて：開発者用機能の予告

SSP には、ゴーストを作る人のための機能がたくさん用意されています。これらは、本体設定の「一般」で **開発者用機能を有効にする** をオンにすると使えるようになります。

オンにすると、次のような変化があります。

- 本体設定に「開発/その他」のページが現れます。
- 右クリックメニューの「機能」に、**スクリプトログ**（ゴーストが話したさくらスクリプトの履歴とエラーの記録）や **開発用パレット**（当たり判定の表示などを切り替える道具箱）が加わります。
- 「開発/その他」の「フォルダをドロップした際に更新ファイルやNARを作成」と組み合わせると、ゴーストのフォルダを SSP にドラッグ＆ドロップするだけで、配布用の nar ファイルやネットワーク更新用のファイル（`updates2.dau`）を作れるようになります。

> **注意**
> 開発者用機能は、ゴーストのロックを外したり、内部の情報を表示したりします。遊んでいるゴーストで使うと、不具合やネタバレの原因になることがあります。ゴーストを作るときだけオンにしましょう。

これらの使い方は、[第14章 テストとデバッグ](14-debug.md) と [第15章 配布とネットワーク更新](15-distribute.md) で詳しく説明します。

## まとめ

- 本体設定は右クリックメニューの「設定」→「本体設定」から開き、ゴーストごとの設定はそれより優先されます。
- SSP のエクスプローラ（Ctrl+E）で、ゴーストなどの一覧・更新・削除をまとめて行えます。
- ヘッドラインは Web の更新情報を読み上げる機能で、RSS にも対応しています。プラグインは SSP 全体に機能を足す部品です。
- 「他のゴーストを呼ぶ」で複数のゴーストを同時に立たせられます。
- アンインストールは右クリックメニューかエクスプローラの「削除」から行います。
- 開発者用機能は、ゴーストを作るときだけオンにします。

## 練習問題

1. ゴーストを二人同時に立たせ、片方だけ別のバルーンに切り替えてみましょう。もう一人のバルーンは変わったでしょうか。

<details>
<summary>答え</summary>

変わりません。バルーンの選択はゴーストごとに記憶されるからです。

</details>

2. ヘッドラインを一定時間ごとに自動で読み上げてもらうには、本体設定のどのページを使いますか。

<details>
<summary>答え</summary>

「接続(2)」のページで、ヘッドラインの「自動的にチェック」をオンにします。

</details>

3. キャラクターが画面の外に出て、右クリックできなくなりました。どうやって元の位置に戻しますか。

<details>
<summary>ヒント</summary>

タスクトレイのアイコンを右クリックすれば、メインキャラクターのメニューが開きます。そこから「機能」→「シェル位置初期化」を選ぶか、Ctrl+Shift+F12 を押します。

</details>

4. 開発者用機能をオンにすると、右クリックメニューの「機能」に増える項目を二つ挙げてください。

<details>
<summary>答え</summary>

スクリプトログ、開発用パレット（ほかに、制限モード強制解除も加わります）。

</details>
